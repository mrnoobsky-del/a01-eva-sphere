## Universal accessibility and family comfort

- [Русский стандарт v0.1](A01-UNIVERSAL-ACCESSIBILITY-v0.1.md)
- [English version v0.1](A01-UNIVERSAL-ACCESSIBILITY-v0.1.en.md)

The A-01 project standard covers accessible circulation, lifts, toilets, showers, family care rooms, wayfinding, operations and inclusive evacuation. It is a concept design requirement set, not a national code or construction approval.
