# A-01 LUNA — 月壤防护模块化月球栖居舱

**概念说明 v0.1 · 2026年11月19日**  
**项目体系：** A-01 / Eva Sphere（伊娃之球）  
**状态：** 独立研究概念。不是 NASA 设计、NASA 背书、飞行合格系统、施工文件或竞赛提交材料。

**语言：** [English](README.md) · [Русский](README_RU.md) · [简体中文](README_ZH.md)

## 1. 核心构想

A-01 LUNA 探索一种模块化月球前哨基地，其设计以功能分离为核心：

1. 紧凑、可运输且保持舱内压力的栖居模块，为乘员提供受保护的生活空间。
2. 独立、可更换的外部防护系统，用于降低月球环境带来的风险。
3. 机器人设备负责场地准备、月壤搬运、防护材料铺设、检查以及部分维护工作。
4. 生命保障、电力、热控、通信、消防安全和运行管理被设计为相互协调但功能独立的系统，并具备本地安全模式和人工监督。

第一阶段的研究目标刻意保持狭窄：**围绕标准栖居模块部署并维护机器人施工的月壤防护系统**。本项目不应试图在一份方案中解决整个月球定居点的全部问题。

暂定名称：**A-01 LUNA — Regolith-Sheltered Modular Habitat（月壤防护模块化栖居舱）**。

## 2. 为什么它是 A-01 的独立分支

地球版 A-01 探索以人为中心的生活空间、模块化组件、可更换外部舱板、工程维护通道、数字化运行以及韧性资源系统。这些设计原则具有参考价值，但不能把地球建筑直接复制到月球。

大型透明穹顶、大面积玻璃、开放式多层中庭以及普通建筑电梯，并不自动适用于月球。它们可能带来较大的质量、密封、热控、辐射防护、月尘控制和维护负担。

因此，A-01 LUNA 保留**模块化和可维护的系统理念**，但允许从基本原理出发重新设计月球结构、布局、材料和运行流程。

## 3. 建议的架构

该概念分为四个功能层：

| 层级 | 作用 | 需要研究的问题 |
|---|---|---|
| 主栖居模块 | 保持压力的乘员空间及必要内部服务系统 | 运输包络、接口、泄漏检测、维修、冗余 |
| 环境边界层 | 热量、月尘、真空及局部污染控制 | 密封件、贯穿件、热桥、月尘隔离 |
| 可更换外部防护层 | 月壤覆盖、土堤、防护屏或就地制造的防护构件 | 所需几何与质量、铺设精度、稳定性、检查与更换 |
| 内部运行体验层 | 宜居环境、显示界面、照明、导航、本地软件和乘员工具 | 人因工程、降低认知负担、手动备用模式、可维护性 |

外部防护层不能悄然承担舱内压力边界的职责。外部防护构件受损或更换，不应自动危及栖居舱的密封性。

### 3.1 候选部署流程

1. 勘察选定场地，核实坡度、地表承载条件、危险因素、光照、通信和通行条件。
2. 准备着陆区和作业区，同时控制发动机羽流和扬尘风险。
3. 使用符合任务要求的货运系统运送并定位标准栖居模块。
4. 在乘员入住前，检查栖居模块接口、压力边界、电力、热控和生命保障连接。
5. 部署机器人设备，在指定防护区域挖掘、搬运、整平或铺设当地月壤。
6. 检查防护结构几何形状及其与栖居模块的接口；确认载荷和间隙处于经验证的限值内。
7. 调试栖居舱及其独立安全系统。未经验证的功能在获得测试证据前应保持隔离。
8. 在可行的情况下，通过可更换构件和机器人检查来维护外部防护层。

以上流程属于规划假设。着陆接口、机器人能力、材料属性、结构载荷和调试程序仍是待解决的工程问题。

### 3.2 就地资源利用

可纳入技术权衡研究的候选方案包括：
- 将松散月壤可控地铺设成防护土堤或覆盖层；
- 使用机械约束结构来容纳月壤的填充式构件；
- 在能够证明工艺能耗、设备、原料和质量控制合理的前提下，就地制造砌块、面板或烧结构件。

这些只是待比较的方案，并非已选定或经验证的施工方法。就地材料工艺必须评估能源需求、扬尘、污染、机械性能、重复性、维修方式和设备磨损。

## 4. 可从地球版 A-01 借鉴的内容

以下理念可以改造使用，但不能证明其已具备月球应用能力：

- **分层系统架构：** 将主体结构、内部环境边界、可更换防护层和内部体验层分开。
- **组件护照：** 为每个可维护组件分配 ID、所属系统、材料记录、位置、生命周期状态、维护计划和证据状态。
- **可维护模块：** 设计外部部件，使其能够在不打开栖居舱的情况下被检查和更换。
- **分离式工程系统：** 协调电力、水、舱内气氛、热控、通信、消防、机器人和运行管理，同时保持各系统可独立保护。
- **数字运行支持：** 通过软件显示系统状态、维护任务、路线和程序；同时保留本地运行和人工恢复能力。
- **以人为中心的设计：** 兼顾隐私、睡眠、工作、休闲、无障碍、乘员自主权和心理健康。

当前地球版数字孪生模型是软件概念，其场景单位尚未经过尺度校准。不能把模型中的视觉尺寸和动画当作月球工程参数。

## 5. 必须研究的月球环境约束

NASA 将月球南极地区描述为持续探索的潜在区域，并强调地表基础设施、电力、机器人、月尘缓解等技术需求。A-01 LUNA 至少必须明确研究以下约束。

### 辐射与微流星体
根据具体任务的辐射与撞击环境，评估防护策略和栖居模块布局。本概念说明不宣称任何防护厚度或剂量降低效果。

### 高磨蚀性月尘
研究月尘通过接口、密封件、连接器、运动关节、散热器、传感器和设备进入系统的风险。设计清洁和检查方法时，应避免不可接受的乘员暴露或设备磨损。

### 极端温度与长时间黑暗
建立针对具体场地和任务的热模型。电力和热控架构必须考虑月球光照周期、储能、生存负载、热量排出以及低活动时期。不能假设所有候选地点都有持续阳光或相同的昼夜条件。

### 真空与压力边界
栖居舱压力容器、舱门、贯穿件、窗户（如有）和对接接口都需要独立验证。外部月壤防护不能替代合格的压力容器。

### 低重力与建造作业
评估挖掘、运输、材料铺设、锚固、扬尘轨迹、设备牵引以及月球重力下的稳定性。不能假设地球建筑机械无需改造即可工作。

### 有限的质量、体积、能源和乘员时间
量化着陆质量、包装体积、部署时间、功率、消耗品、备件、乘员时间和机器人工作周期。应尽量减少不必要的复杂度和来自地球的补给。

### 自主运行与通信
当通信中断时，基本控制和安全功能仍须在本地运行。远程监督可以提供帮助，但系统不能依赖持续的地球通信或不间断的人工干预。

NASA 主要参考资料：[Lunar Surface Technology](https://www.nasa.gov/lunar-surface-technology/)。

## 6. 首个工程验证样机

首个验证样机应是一个全尺寸或适当缩比的**栖居模块与防护层接口样件**，而不是完整基地。

建议的测试计划：
1. 具有代表性的栖居舱密封舱壁/接口样件。
2. 可更换外部防护构件及其固定、检查特征。
3. 小型机器人搬运或铺设演示。
4. 对代表性接缝和连接器进行月尘进入与污染测试。
5. 与合格实验室及适用标准共同规划热真空和机械测试。
6. 故障场景：错位、机构卡滞、断电、传感器故障、防护构件损坏以及通信中断。
7. 制定不需要打开栖居舱的人工或机器人恢复流程。

样件的材料、几何形状、质量、作用力、温度和验收标准必须由合格工程人员确定。在测试之前，不宣称任何性能。

## 7. 证据状态与工程关口

项目中的每个数值都应标记为以下状态之一：**未知、假设、建议、已计算、已审查、已测试、已批准或已建成实测**。

在宣称方案可行之前，项目还需要：
- 选定任务场景、乘员人数、任务时长和场地假设；
- 质量与运输包装体积预算；
- 结构载荷路径和岩土工程假设；
- 月壤属性及搬运测试证据；
- 辐射与微流星体防护分析；
- 热真空分析和散热策略；
- 发电、储能、配电和生存负载估算；
- 生命保障接口和资源预算；
- 月尘控制、消防安全、应急和维护计划；
- 机器人作业及故障恢复分析；
- 人因工程和乘员宜居性审查；
- 合格专业人员的独立审查。

动画、渲染图、电子表格估算或数字孪生都不是系统鉴定试验或安全认证。
