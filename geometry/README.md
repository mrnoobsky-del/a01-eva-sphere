# A-01 parametric geometry

The files in this directory record proposed, reproducible geometry derived from the digital twin. They use uncalibrated model units unless a controlled scale and datum are explicitly published.

- [Shell parameters](a01-shell-parameters-v0.1.json)
- [Generated cassette layout — 144 candidates](a01-cassette-layout-v0.1.json)
- [Cassette layout diagram](cassette-layout-diagram-v0.1.svg)
- [Parametric geometry methodology](../architecture/A01-CAS-PANEL-GEOMETRY-v0.1.md)
- [Generator](../tools/generate-cassette-layout.mjs)
- [CSV cassette register](../templates/cassette-layout-register-v0.1.csv)

The 12 sectors are parent zones. The 144 generated records are candidate replaceable modules, not an approved production schedule. The geometry does not establish physical dimensions, structural performance or construction readiness.
