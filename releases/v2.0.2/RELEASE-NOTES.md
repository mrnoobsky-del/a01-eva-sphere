# A-01 v2.0.2 — Mobile UX preview

Date: 2026-11-12

## Changes

- Simplified the mobile first screen by removing the duplicate intro block above the 3D stage.
- Increased mobile heading, metadata, and action-control sizes for legibility.
- Replaced the single right-side walk D-pad with two separated thumb zones: movement on the left, camera rotation on the right.
- Corrected camera rotation direction so left rotates left and right rotates right, matching the existing drag gesture.
- Increased touch targets to 50–54 CSS px and added visible press feedback.

## Validation status

Preview build based on v2.0.1. Static source transformations were checked. Physical iOS/Android device testing and browser-viewport visual testing are still pending. Keep v2.0.1 as the stable reference until testing is complete.
