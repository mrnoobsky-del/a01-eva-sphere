AIR-01 将月球外部资源处理与栖居舱洁净生命保障分开。模型展示 MRE 反应器、气体调质、双重传输边界、水电解、CO₂ 捕集、Sabatier 处理、缓冲储罐和分配管线。

该模型仅为软件概念。没有连接真实设备、遥测或控制系统。场景尺寸尚未校准，工程尺寸设计未完成，也未进行实体或安全验证。已完成源代码级 JavaScript 语法检查；当前环境未完成真实浏览器/WebGL 漫游测试。
