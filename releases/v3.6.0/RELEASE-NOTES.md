# A-01 v3.6.0 — AIR-01 life-support integration

This release adds a conceptual autonomous atmosphere system to the A-01 digital twin.

AIR-01 separates external lunar-resource processing from clean habitat life support, and shows an MRE reactor, gas conditioning, a double-boundary transfer interface, water electrolysis, CO₂ capture, Sabatier processing, buffers and distribution routes.

The model is a software concept only. It has no live equipment, telemetry or control. Scene dimensions are not calibrated, no engineering sizing is complete, and no physical or safety validation is claimed. A source-level JavaScript syntax check was completed; a live WebGL browser walk-through was not completed in this environment.
