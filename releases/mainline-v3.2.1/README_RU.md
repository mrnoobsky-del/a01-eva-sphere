# A-01 v3.2.1 — Navigation Flow

Исправлено поведение бокового меню на desktop/tablet: раскрытие меню резервирует свою колонку, сдвигает центральную сцену вправо и сужает её вместо перекрытия контента. При сворачивании центральная область возвращает ширину. Мобильное меню остаётся overlay drawer.

Сборка основана на v3.2.0 Local 3D Engine; сохраняет локальные относительные импорты Three.js r185 и исправления режима изучения объектов.
