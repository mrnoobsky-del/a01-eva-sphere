# A-01 v3.2.2 — открытие одним HTML-файлом

## Для чего эта сборка

Эта версия предназначена для запуска двойным щелчком по HTML-файлу, в том числе при адресе страницы file://. Папка vendor/, PowerShell-скрипты, BAT-файл и локальный HTTP-сервер не требуются.

## Важное ограничение

Сборка не является полностью автономной офлайн-версией. Three.js r185 и OrbitControls загружаются из jsDelivr через import map. Для запуска нужно интернет-соединение и доступ к cdn.jsdelivr.net.

Если требуется работа 3D-сцены без интернета после первоначальной установки библиотек, используйте v3.2.1 Local Engine: распакуйте архив полностью и запустите START-A01-OFFLINE.bat. Не открывайте HTML этой версии двойным щелчком, так как браузер ограничивает ES-модульные импорты file://.

## Выбор варианта

| Требование | Версия |
|---|---|
| Открыть один HTML двойным щелчком, интернет есть | v3.2.2 Single HTML |
| Работать с локальными файлами движка после подготовки | v3.2.1 Local Engine |
| Полностью офлайн с первого запуска без дополнительной подготовки | Отдельный полностью встроенный build ещё не подготовлен |

## Сохранённые возможности

- v3.2.1: боковое меню резервирует собственную колонку и сужает центральную область.
- v3.1.9: полноэкранный режим изучения объектов.
- v3.1.8: пространственные исправления.
- v3.1.7: Agent Runtime.

Чат Евы, внешние ссылки и некоторые подключаемые сервисы остаются сетевыми функциями независимо от способа запуска 3D-сцены.

## Проверки и статус

HTML проверен парсером, 324 уникальных ID без дубликатов. Встроенный модуль проходит node --check. Проверка режима изучения объектов проходит. ZIP целостен.

Фактический браузерный запуск CDN из file:// в текущей среде не выполнен, поскольку у среды сборки нет внешнего сетевого доступа. Поэтому проверено содержимое/синтаксис файла, но не подтверждена доступность jsDelivr из конкретной сети пользователя.
