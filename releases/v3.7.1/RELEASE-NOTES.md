# A-01 v3.7.1 — release notes

## Русский
- Уточнена последовательность шлюза Gull-wing: наружная створка закрывается до открытия внутренней границы.
- Добавлена программная блокировка от одновременного открытия двух границ в визуальной модели.
- Добавлен отдельный зимний сценарий потери питания с визуальным закрытием короны.
- Калькулятор показывает зимний расход и ориентировочные теплопотери при открытой короне.
- Исправлены метаданные версии на 3.7.1.

## English
- Re-sequenced Gull-wing so the outer hatch is closed before the inner boundary opens.
- Added a software-level mutual-interlock guard to the visual demonstrator.
- Added a separate winter power-loss mode with a closed-crown visual target.
- Added winter open-crown airflow and estimated heat-loss metrics.
- Corrected version metadata to 3.7.1.

## 简体中文
- 调整 Gull-wing 顺序：外舱门关闭后才打开内侧边界。
- 为可视演示模型增加双门互锁保护。
- 增加冬季断电演示模式，冠部通风口目标为关闭。
- 增加冬季冠部开启时的气流量和估算热损失指标。
- 将版本元数据修正为 3.7.1。

**限制 / Limitations / 限制：** This is a digital-twin concept only. No physical interlocks, sensors, actuators, HVAC or fire-safety equipment are connected. The calculations are preliminary and require engineering review. Browser/WebGL and phone validation are still pending.
