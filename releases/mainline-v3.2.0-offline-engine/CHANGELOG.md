# A-01 v3.2.0

- Three.js r185 и OrbitControls переведены с CDN на относительные локальные пути.
- Исходники движка находятся в vendor/three; three.core.js собирается из двух проверяемых частей.
- Добавлен PowerShell bootstrap для первой установки.
- Добавлен локальный HTTP-сервер запуска, необходимый браузерным ES-модулям.
- Ошибка загрузки теперь указывает на локальную папку движка и установщик, а не предлагает проверить CDN.
- Сохранены режим изучения объектов v3.1.9, пространственные исправления v3.1.8 и Agent Runtime v3.1.7.

Ограничение: ZIP-архив не содержит полный набор бинарных/исходных файлов Three.js. При первом запуске он один раз получает их с GitHub Raw. После этого 3D-сцена использует локальную копию и может запускаться без сети. Чат Евы и внешние ссылки остаются сетевыми.
