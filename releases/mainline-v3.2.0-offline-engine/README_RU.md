# A-01 v3.2.0 — локальный 3D-движок

В v3.1.9 сцена импортировала Three.js r185 и OrbitControls с jsDelivr. При недоступности CDN запуск 3D-сцены прекращался.

В v3.2.0 import map указывает на локальные файлы:
- vendor/three/build/three.module.js
- vendor/three/build/three.core.js
- vendor/three/examples/jsm/controls/OrbitControls.js

## Первичная подготовка

Архив включает HTML, установщик и скрипт локального HTTP-сервера. При первом запуске установщик получает точные официальные исходники Three.js r185 из этого GitHub-репозитория, проверяет их содержимое и собирает three.core.js из двух частей. Это одноразовый этап, для него нужен доступ к GitHub Raw.

После успешной подготовки движок хранится локально и при последующих запусках не обращается к CDN или сети. Локальный HTTP-сервер нужен для корректной работы ES-модулей браузера; запуск HTML напрямую через file:// не используется.

## Запуск Windows

1. Распаковать комплект в одну папку.
2. Запустить START-A01-OFFLINE.bat.
3. Дождаться завершения первичной загрузки Three.js.
4. Страница откроется через localhost.
5. При следующем запуске повторная загрузка не требуется.

## uCoz

После первичной подготовки загрузить HTML и всю папку vendor/ с сохранением относительной структуры. Загружать только HTML недостаточно.

Чат Евы обращается к Cloudflare Worker и остаётся сетевой функцией. Автономный режим относится к 3D-движку и сцене, а не ко всем внешним сервисам проекта.
