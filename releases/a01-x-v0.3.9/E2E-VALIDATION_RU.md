# A-01 X v0.3.9 — сквозная проверка Agent Runtime и MCP

**Дата:** 22 ноября 2026 года  
**Основа:** A-01 X v0.3.8 Agent Runtime / Mission Manager.

v0.3.9 добавляет автоматический сквозной набор проверок для цепочки MCP → локальный HTTP API → browser bridge → Agent Runtime → Agent Manager. Изменение этой версии — качество и проверяемость интеграции. Физический робот и внешняя LLM не подключаются.

## Что проверяет E2E-набор

- Запускает локальный HTTP-сервер A-01 на loopback-порту и отдельный Python MCP stdio-процесс.
- Публикует тестовую карту и состояние через browser bridge API.
- Проверяет чтение карты MCP-клиентом и отсутствие удалённых инструментов подтверждения/исполнения миссий.
- Проверяет, что go_to, walk_route, pose, look и look_at через MCP создают только заявки pending_approval.
- Проверяет отсутствие движения до разрешения оператора и безопасную отмену ожидающей миссии.
- Выдаёт тестовое операторское разрешение через Runtime, выполняет миссию и проверяет публикацию статуса обратно в MCP.
- Отклоняет неизвестные waypoint ID и прямые HTTP-команды движения/позы/взгляда.
- Проверяет немедленный Stop.
- Статически проверяет, что публичный window.A01Agent.runtime не раскрывает approveMission и executeMission, а браузерный Mission Manager остаётся точкой подтверждения.

## Границы проверки

Тест использует настоящий локальный HTTP-сервер, настоящий MCP-процесс, реальные обработчики API, production A01AgentRuntime и контракты интерфейса из index.html. Вместо Three.js-сцены применяется тестовый адаптер Android-01: проверяется передача команд, политика разрешений и поток статусов, но не физика, анимация, реальные DOM-клики в браузере или GPU. Отдельный аудит геометрии включает 190 статических проверок.

WebGL/browser acceptance, реальная навигация по mesh/NavMesh, физические приводы и аппаратный Android-01 не проверялись.
