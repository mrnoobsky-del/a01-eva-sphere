# Сфера Евы A-01 · v3.0 experimental

Экспериментальная цифровая версия с параметрической сеткой из 144 наружных кассет. Не является рабочей документацией или подтверждением несущей способности.

## Состав
- `digital-twin/eva-sphere-a01-v300-modular-shell.html` — загрузчик v3.0, собирающий сцену из стабильной v2.1.0 и слоя кассет.
- `digital-twin/eva-sphere-a01-v300-cassette-layer.js` — код наружной кассетной сетки и выбора панелей.
- `geometry/a01-cassette-layout-v0.1.json` — исходные данные геометрии.

## Ограничения
144 панели — геометрические кандидаты, не готовые изделия. Model-unit не откалиброван в метры. Материалы, масса, толщина, крепёж, нагрузки, пожарные и водные характеристики остаются TBD. Радиальный коэффициент 1.006 — визуальный отступ, не монтажный зазор. Корона и нижний пояс требуют отдельных узлов. Физические испытания и инженерные согласования не проводились.

Загрузчик работает через HTTP(S), например GitHub Pages; `file://` не поддерживается из-за браузерного `fetch`.
