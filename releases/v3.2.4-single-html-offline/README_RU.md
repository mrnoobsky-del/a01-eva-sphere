# A-01 v3.2.4 — Single HTML Offline

**Файл:** `eva-sphere-a01-v324-single-html-offline.html`

Three.js r185 (core + module) и OrbitControls r185 встроены непосредственно в HTML. Для запуска 3D-сцены не нужны CDN, папка `vendor`, установщик или локальный HTTP-сервер.

## Запуск
Открой HTML двойным щелчком в актуальном Chrome или Edge. Сцена создаёт временные Blob-модули из включённых в файл исходников.

## Границы автономности
3D-движок и построение сцены находятся внутри HTML. Чат Евы, Cloudflare Worker, внешние ссылки и удалённые сервисы по-прежнему требуют интернет. Для 3D-сцены требуется поддержка WebGL.

## Проверка
Проверено, что в HTML нет import map, внешнего URL Three.js и ссылок на `vendor/three`. Связка модулей через Blob URL отдельно проверена в Chromium на тестовом модульном примере. Запуск полного файла через `file://` на целевом компьютере пока не подтверждён.
