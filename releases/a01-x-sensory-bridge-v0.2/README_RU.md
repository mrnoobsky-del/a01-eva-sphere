# A-01 X Sensory Bridge v0.2 — Living Perception Loop

**Сфера Евы · Android-01 · Sphere Intelligence**  
**Дата:** 22 ноября 2026 года  
**Статус:** документационный выпуск архитектуры и контрактов интеграции.

## Что изменилось относительно v0.1

v0.1 задал перечень каналов восприятия и общую архитектуру. v0.2 уточняет, как эти каналы становятся согласованным наблюдением и как наблюдение превращается в проверяемую инженерную задачу.

- Реестр сенсоров с привязкой к телу Android-01, координатным рамкам и структуре Sphere → Level → Zone → Room → Asset.
- Строгие формы данных для RGB/Depth, IMU, суставов, сил, позы и скалярных измерений среды.
- Разделение разрешений на съёмку, передачу и хранение.
- Контроль синхронизации времени, свежести, калибровки и происхождения данных.
- Контур восприятия: видимые факты, сенсорные факты, вычисленные признаки, гипотезы и неизвестное.
- Журнал от исходного наблюдения до инженерной загадки, рекомендации, разрешения, действия и повторной проверки.
- Отказные режимы и приёмочные критерии.

## Как читать пакет

1. Проверьте envelope и версию схемы.
2. Сопоставьте каждый source_id с реестром sources.
3. Проверьте frame_id, координатные рамки и timestamp.
4. Проверьте provenance и quality.
5. Убедитесь, что нужное разрешение активно для соответствующего типа данных.
6. Не запускайте sensor fusion, если данные не синхронизированы или имеют неприемлемое качество.

## Статус реализации

Выпуск не подключает реальную камеру, микрофон, IMU, датчики Android-01, физический привод или BMS. Примеры помечены как simulation и не являются телеметрией реального устройства. Для реализации нужен точный исходный runtime Android-01, аппаратные интерфейсы и отдельный план безопасных испытаний.

## Основной принцип

Android-01 наблюдает и проверяет. Sphere Intelligence связывает наблюдение с картой и инженерными системами. ИИ предлагает гипотезы и действия, но локальная безопасность и человек сохраняют контроль.

## Проверка схем и примеров

Из корня репозитория:

```bash
python -m pip install -r requirements-dev.txt
python tools/validate-sensory-bridge-v0.2.py
```

Проверка использует JSON Schema Draft 2020-12, проверяет оба примера, ссылки observation → source/frame, срок действия media-ссылок, разрешение на аудио и последовательность журнала событий. GitHub Actions запускает ту же проверку при изменениях файлов выпуска.
