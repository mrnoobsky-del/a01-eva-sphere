# A-01 X v0.3.8 — Agent Runtime / Mission Manager

**Основа:** v0.3.7 · **Дата:** 22 ноября 2026  
**Статус:** интегрированный программный прототип Agent Runtime для цифрового Android-01; физический робот не подключён.

## Назначение

Agent Runtime связывает Agent World, AgentEyeCamera и Sensory Bridge в контролируемый цикл:

**цель → план → проверка → разрешение оператора → последовательное выполнение → верификация → журнал.**

Модель может предложить JSON-план, но не получает произвольный доступ к JavaScript, Three.js, костям, суставам или приводам. Runtime проверяет аргументы и использует только разрешённые высокоуровневые инструменты.

## Что добавлено

- Mission Manager в панели «Агент».
- Каталог инструментов и политика Allow / Ask / Deny.
- JSON Schema плана миссии: до 12 шагов и до 8 известных точек маршрута.
- Одобрение оператором в браузере, сроком не более 10 минут.
- Последовательное выполнение и проверка прибытия через inspect().
- Отмена, немедленная команда Stop и RAM-журнал событий.
- MCP stdio с 16 инструментами и безопасным предложением миссий.
- Запрет прямого HTTP/MCP обхода для движения, позы и поворота головы.

## Связь с Google Antigravity

Antigravity не встроен как продукт или SDK. Его принципы агентного планирования, инструментов, делегирования ролей и разрешений использованы как ориентир. Antigravity или другой MCP-клиент может подключиться к локальному A-01 через stdio; самостоятельное одобрение миссии недоступно.

## Проверки

Локальный npm run check прошёл: 17-костный риг, 8 проверок AgentEyeCamera, 8 проверок Agent Runtime, Sensory Bridge/API, HTTP API, MCP stdio и 190 проверок геометрии/UI. JSON Schema Draft 2020-12 и пример плана проверены.

## Ограничения

Роли Planner / Navigator / Perception / Action Executor / Verifier / Safety Supervisor — разные обязанности одного Runtime, а не шесть параллельных нейросетей. Провайдер модели автоматически не подключён. Android-01 — Three.js симуляция; кадры имеют provenance: simulated. Физические камеры, ROS 2, приводы и BMS отсутствуют. Браузерная WebGL/GPU-приёмка на целевом устройстве ещё не проведена.
