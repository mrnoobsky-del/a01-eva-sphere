# A-01 X v0.3.0 — Sphere Intelligence and Human Wellbeing

**Release type:** documentation-only research/specification release  
**Date:** 22 November 2026  
**Branch:** A-01 X experimental line, following v0.2.0

## Summary

This release establishes a riddle-driven engineering method and a human-centred Sphere Intelligence specification. It shifts the design objective from “make the avatar endure the building” to “design the building to reduce avoidable human burden and support recovery.”

## Added

- Riddle-to-engineering workflow and machine-readable riddle card schema.
- Twelve connected subsystem domains.
- Data quality, privacy, independent safety and human-approval architecture.
- 13-hour long-duration occupancy test protocol.
- Normal, peak, fault and recovery scenarios.
- Reference register for standards and open modelling tools.
- RU / EN / Simplified Chinese documentation.

## Validation

- Documentation links and JSON files are included in this release.
- This is a document specification, not an executable software feature.
- No building equipment, sensors, BMS or robot hardware is connected.
- No thermal, airflow, acoustic, lighting, water or code-compliance calculation was completed by this documentation publication.

## Important interpretation

“13 hours” is a test window for occupancy and infrastructure operation with activity changes and recovery opportunities. It is not a continuous-work target, fatigue-free guarantee or clinical claim.

Previous v0.1.0 and v0.2.0 files are preserved.
