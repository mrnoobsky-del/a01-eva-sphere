# A-01 X 测试协议：在球体中 13 小时

**ID：**A01X-HWT-13H · **版本：**0.1  
**状态：**拟议仿真协议，不是真实建筑的测试结果

## 1. 13 小时的含义

这是长期使用和基础设施运行的测试时间窗，包含不同活动、移动、饮水、进食、休息、隐私和访客数量变化。它不表示一个人连续工作 13 小时，也不承诺所有人都不会疲劳或紧张。目标是减少可避免的负担、避免有害条件并提供可达的恢复空间。

## 2. 合成使用者场景

使用不包含身份信息的合成场景：普通移动访客；需要无障碍路线和频繁座椅的访客；对噪声、亮度或温度敏感的人；有照护需求的家庭；偏好安静和较少社交的人；长时间工作的维护人员；造成排队和额外热负荷的高峰人群。

这些是负载场景，不是医疗诊断。真实场地建成后，应另行进行自愿参与的测试和无障碍专家咨询。

## 3. 时间序列

| 时间 | 建筑场景 | 检查 |
|---|---|---|
| 00:00–01:00 | 到达、方向识别、人群分布 | 入口、排队、导航、通行和微气候 |
| 01:00–03:00 | 安静活动、工作、学习或等待 | 温度、照明、座椅、空气和视觉负担 |
| 03:00–04:00 | 移动和短暂恢复 | 电梯、扶梯、短路径和休息点 |
| 04:00–06:00 | 用餐、厨房和卫生间使用 | 水、排风、气味、噪声、流线和清洁 |
| 06:00–08:00 | 社交活动和高占用 | 声学、CO₂ 指标、室外风量和热负荷 |
| 08:00–10:00 | 活动减少、休息和独处 | 夜间照明、安静区、隐私和导航 |
| 10:00–12:00 | 室外条件变化或设备故障 | 预测、备用切换和故障隔离 |
| 12:00–13:00 | 人流降低、维护和恢复 | 安全维护、参数复核和事件日志 |

这只是测试顺序，不是访客日程。饮水、卫生和休息在整个测试期间都必须可达。

## 4. 观察指标

每个区域保存时间序列、单位、传感器位置/高度、数据质量、校准和来源：空气/表面温度、湿度、风速；实际送风和排风、CO₂、风险相关污染物、PM2.5/PM10、CO 和必要时的 VOC；区域压差和气流方向；照度、眩光和时间模式；噪声峰值、频谱和混响；汇总占用和排队、电梯等待时间；到饮水、座椅、卫生间、淋浴和安静室的无障碍距离；电力、通风、过滤、水路和控制系统状态。

传感器不是医疗设备。CO₂ 不是完整空气评估；VOC 传感器不能识别所有化学物质；压力读数不能证明房间安全。关键测量须专业选型和校准。

## 5. 故障场景

测试高温和屋顶太阳得热、寒冷与结露、室外污染、高峰占用、通风机组故障、淋浴湿度峰值、电梯停运、电网断电、云/网络断开、传感器失准、滤网/泵/阀门故障以及火灾和烟雾边界条件。每种情况都要记录预期行为、发现时间、降级模式、人工通知、恢复和失败条件。

消防、排烟、疏散、电梯安全回路和应急电源由独立系统和合格工程师依据适用规则设计与验证。AI 不得覆盖这些保护。

## 6. 通过条件

本协议不设定全球通用的温度、CO₂、噪声、照度或压力阈值。数值应根据场地、气候、房间用途、国家法规和适用标准版本确定。

只有满足以下条件才通过：占用区域符合适用安全与法规要求；偏离的时长和幅度被记录；每层有连续无障碍路线；水、卫生间、座椅和休息空间始终可达；空气、温度、光和声按区域及时间评估；传感器/网络/电力/设备故障有已定义的降级模式；AI 命令有限、可审计、可撤销且不绕过保护；校准、不确定性和缺失数据可见。

## 7. 报告指标

分别报告每个区域符合要求的占用时间比例、偏离持续时间和恢复时间、传感器数据质量、各区域实际室外风量、竖向温度分布、电梯等待时间、无障碍路线长度、到座椅/水/卫生设施距离、房间类别的噪声和语音隐私、能源影响、故障/误报/人工干预和回滚情况。不要给出一个综合舒适分数。

## 8. 证据成熟度

T0 概念；T1 分析模型；T2 可重复仿真；T3 控制器硬件在环模拟；T4 建成场地校准仪器和系统调试；T5 运营期重复测量、维护、自愿反馈和独立审查。

v0.3.0 仅记录协议；该综合场景仍处于 T0，不证明真实建筑适合 13 小时使用。
