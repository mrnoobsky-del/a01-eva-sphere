# A-01 X v0.3.0 — Sphere Intelligence（球体智能）

**伊娃之球 · 能源 · 智能 · 生命**

这是 A-01 X 实验技术线的文档版本。目标是把“球体应当照顾人”转化为可检查的设计、仿真和未来运行要求。

> **核心原则：** 人不应被迫弥补建筑的缺陷。球体应主动发现并减少可避免的负担，提供无障碍通行和恢复空间。

## 本版本内容

- “谜题 → 假设 → 要求 → 模型 → 测试 → 证据 → 决策”的工程方法。
- Sphere Intelligence 是主要设计对象；Android-01 负责巡检，Human Proxy 使用合成场景评估不同使用需求。
- 十二个关联领域：空气、气候、照明、声学、水、移动、卫生、营养、休息与认知舒适、生态绿化、能源韧性和数字安全。
- 13 小时长期使用测试协议，包含正常、峰值和故障场景。
- 隐私、传感器质量、独立安全系统、维护和人工控制要求。

## “13 小时”的含义

这是长期使用和基础设施运行的测试时间窗，不表示要求一个人连续工作 13 小时而不休息。测试包括不同活动、移动、饮水、进食、休息和个人空间。项目不宣称能消除疲劳、保证医疗效果或适用于所有人的统一舒适度。

## 状态

v0.3.0 是**纯文档版本**。它扩展了设计要求和测试计划，但没有连接真实传感器、楼宇管理系统、通风、照明、供水、电梯或执行器。它不是施工文件，也不是安全认证。
