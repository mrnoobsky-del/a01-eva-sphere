# A-01 X v0.3.0 — Sphere Intelligence

**Sphere of Eva · Energy · Intelligence · Life**

A documentation release for the experimental A-01 X line. It turns the idea that “the Sphere should care for people” into a testable architecture for design, simulation and future operation.

> **Core principle:** people should not have to compensate for building deficiencies. The Sphere should detect and reduce avoidable burdens, provide access and make recovery possible.

## What is new

- A repeatable method: riddle → hypotheses → requirement → model → test → evidence → decision.
- Sphere Intelligence as the primary design subject; Android-01 as an inspector and Human Proxy as synthetic evaluation profiles.
- Twelve connected domains covering air, climate, light, acoustics, water, movement, sanitation, nourishment, rest and cognitive comfort, biophilia, energy resilience and digital security.
- A 13-hour long-duration occupancy test with normal, peak and failure modes.
- Explicit privacy, sensor-quality, independent safety, maintenance and manual-control requirements.

## What “13 hours” means

It is a test window for long-duration occupancy and infrastructure operation, not a requirement to work for 13 hours without rest. The sequence includes different activities, movement, food, water, pauses and privacy. No claim is made that fatigue can be eliminated, that a medical benefit is guaranteed, or that one comfort profile fits everyone.

## Status

v0.3.0 is a **documentation-only release**. It expands requirements and test planning but does not connect real sensors, BMS, ventilation, lighting, water, elevators or actuators. It is not construction documentation or a safety certification.
