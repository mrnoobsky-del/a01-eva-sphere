# A-01 v3.2.4 — Single HTML Offline

Файл `eva-sphere-a01-v322-single-html-offline.html` содержит встроенные:
- Three.js r185 (ядро и основной модуль);
- OrbitControls r185.

## Запуск
Открой HTML двойным щелчком в актуальном Chrome или Edge. Для запуска 3D-движка не требуются CDN, папка `vendor`, установщик или локальный HTTP-сервер.

## Границы автономности
Сам движок и генерация 3D-сцены встроены в файл. Чат Евы, Cloudflare Worker, внешние ссылки и любые удалённые сервисы по-прежнему требуют интернет. Для 3D-сцены требуется поддержка WebGL.

## Проверка
Проверено наличие всех трёх встроенных модулей, связей между blob-модулями, отсутствие import map, внешнего URL Three.js и ссылок на `vendor/three`. Связка модулей отдельно проверена в Chromium на тестовом модульном примере. Запуск именно полного HTML через `file://` на целевом компьютере пока не подтверждён.
