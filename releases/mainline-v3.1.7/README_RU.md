# A-01 v3.1.7 — Mainline Agent Runtime

## Назначение
Перенести полезный ограниченный Agent Runtime из экспериментов X в основную веб-сборку Сферы Евы, сохранив текущую архитектурную сцену и интерфейс сайта.

## База
Текущая опубликованная линия сайта: A-01 v3.1.6, build `3.1.6-gullwing-crown-vent-calcs`. Сборка v3.1.7 подготовлена на основе наиболее свежего предоставленного HTML-снимка от 21 ноября 2026 года (1 563 862 байта), чьи build-метаданные совпадают с текущей страницей. Побайтовое сравнение с origin-файлом хостинга недоступно.

## Что перенесено
1. Procedural Android-01 (17 bones).
2. Agent Runtime с проверкой структуры плана, allowlist, явной авторизацией, отменой и проверкой прибытия.
3. AgentEyeCamera как локальная камера на кости головы, запускаемая отдельно пользователем.
4. Адаптер к существующей `EVA_SPHERE` сцене; вторая Three.js-сцена не создаётся.
5. Раздел Android-01 в навигации и панель: карта, выбор места, предложение миссии, подтверждение, отмена, Stop и локальный просмотр камеры.

## Проверки
- Syntax checks модулей и встроенного ES-модуля — PASS.
- `node tests/mainline-agent-adapter-check.mjs` — PASS.
- Проверены пять уровней, существующие объекты как назначения, межуровневый маршрут, прибытие, границы позы/взгляда, Stop и запрет старта до подтверждения.

## Ограничения
Маршрутная карта концептуальная: 24 точки галереи на уровень, 3 условных межуровневых коннектора. Не реализованы navmesh, физические коллизии, crowd flow, калибровка метров, анализ доступности или эвакуации. Внешняя LLM, Sensory Bridge, MCP и HTTP tools не подключены. Нет камеры физического устройства, приводов и управления зданием. Одобрение в браузере не является сертифицированной физической системой безопасности.

**Статус:** Prototype / локальная автоматическая проверка пройдена. Сборка HTML подготовлена, но автоматически на uCoz не опубликована. Перед ручной публикацией сохраните копию текущей страницы и проверьте её в обычном браузере на desktop/mobile. Полный HTML поставляется отдельным ZIP.
