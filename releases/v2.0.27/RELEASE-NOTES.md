# A-01 v2.0.27 — Modular shell, waste logistics and underground data-centre concept

**Track:** experimental design-study snapshot. This archive does not replace the repository's main v2.1.0 digital-twin baseline.

## Included
- Modular dome with individually identified exterior cassettes and interior digital-sky sectors.
- Visual demonstration of the cassette service cycle and sealed waste-container transfer.
- Floor-level waste stations and a conceptual goods route to the external collection dock.
- Underground data-centre zone with compute, network, storage, power and cooling concepts.
- Human-centred access model: core life-support is independent of income; premium configurations are optional spatial/aesthetic choices.
- Restrained voluntary support link in the navigation rail; it opens YooMoney in a new tab and does not gate any function.

## Static checks
- Seven inline JavaScript blocks passed `node --check`.
- 234 HTML IDs checked; no duplicates found.
- Embedded JSON data block validated.
- The support anchor points to the project's supplied YooMoney link.

## Not verified
Full browser/WebGL and mobile-device testing, uCoz macro expansion, production Worker connectivity, deployment and physical engineering tests have not been completed. External Three.js modules require network access.

Panel movement and waste-container descent are digital-twin demonstrations, not validated machinery. Geometry coordinates are illustrative model units, not certified construction dimensions. No loads, fastener sizes, foundations, wind/snow/seismic design, fire strategy, evacuation study, electrical protection, cooling capacity or bill of materials have been approved.
