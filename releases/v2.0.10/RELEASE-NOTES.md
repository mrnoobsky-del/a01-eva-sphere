# A-01 v2.0.10 — Light Default

Дата публикации: 13 ноября 2026 года.

## Изменения

- Светлая жемчужная палитра назначена темой по умолчанию.
- Для нового посетителя начальный режим темы — `light`; системная настройка тёмного оформления больше не переключает страницу автоматически.
- Сохранённый выбор пользователя `auto`, `light` или `dark` продолжает учитываться.
- Тёмная тема остаётся доступной вручную.
- Метаданные `a01-release` согласованы с версией `2.0.10`.

## Проверки

- Синтаксис трёх исполняемых встроенных JavaScript-блоков проверен через Node.js: ошибок не обнаружено.
- Проверка отрисовки WebGL в браузерах, мобильных устройств и интеграции с production-средой не проводилась.
- Этот архивный снимок не означает развёртывание на публичном сайте.

## Статус и место в истории

Это отдельный архивный снимок ветки v2.0.10 с темой Light Default. Он не заменяет более поздний цифровой двойник v2.1.0, который остаётся текущей более поздней версией в каталоге `digital-twin/`.
