# A-01 v2.0.3 — Desktop clarity and dedicated Eva chat

Date: 2026-11-12

## Changes

- Reorganized the navigation into three clear groups: Main, Systems & Environment, Knowledge & Project.
- Added a dedicated “Chat with Eva” navigation destination, separate from the floating quick-chat button.
- Dedicated chat view uses the existing Eva chat interface and Worker endpoint; it does not create a second chat backend.
- Increased desktop and mobile typography for navigation, headings, body copy, cards, controls, and chat messages.
- Increased spacing and minimum control heights for more comfortable desktop and mobile use.

## Validation status

Preview based on v2.0.2. Source-level changes were applied and checked for expected selectors and handlers. Browser rendering, responsive breakpoints, chat send/receive, and keyboard/touch behavior still require visual and functional testing. v2.0.1 remains the stable reference; v2.0.2 remains the previous mobile preview.
