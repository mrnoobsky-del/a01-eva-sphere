## Главное в версии

В качестве основной зафиксирована интегрированная HTML-линия A-01 с переработанными полыми дольками, входными тамбурами, двумя последовательными дверными плоскостями, створками на петлях, согласованным кольцевым маршрутом и камерой на высоте глаз аватара.

Модель содержит пять уровней и 60 радиальных модулей. Встроенные маркеры вертикальной навигации относятся к интерфейсным переходам, а не к готовым физическим лестницам.

## Статус верификации

Статические проверки пройдены: 298 HTML ID без дубликатов, 7 встроенных JavaScript-блоков без синтаксических ошибок, import map — валидный JSON. Проверка не включает визуальный WebGL-прогон.

Текущая опубликованная uCoz-страница на дату выпуска всё ещё помечена как v3.1.6. GitHub не публикует изменения на сайт автоматически.

## Ограничения

Единицы сцены условные; файл не является BIM/IFC, проектной документацией, расчётом конструкций, доступности, эвакуации, ОВиК или других инженерных систем. Для запуска текущего HTML требуется интернет-соединение и WebGL (Three.js 0.185.0 с jsDelivr).
