# A-01 X — Сфера Евы

**Энергия · Интеллект · Жизнь**

A-01 X — экспериментальная технологическая линия проекта «Сфера Евы». Она продолжает A-01, сохраняет накопленные архитектурные и инженерные решения и проверяет новую браузерную 3D-архитектуру: более производительный рендеринг, модульную сцену, единые параметры геометрии и ясные границы будущих инженерных подсистем.

Это программный прототип и открытая запись проектирования. Физический комплекс не представлен как построенный, подключённый или введённый в эксплуатацию. Предыдущие версии A-01 остаются в истории проекта.

## Первый выпуск

- Процедурный центральный атриум с пятью уровнями и большим открытым вертикальным пространством.
- Обзорная камера и прогулка от первого лица на компьютере.
- Мосты, галереи, стеклянный лифт, озеленение и архитектурное освещение.
- PBR-материалы и окружение RoomEnvironment.
- Профили Low / Medium / High / Ultra и автоматическая адаптация качества.
- Интерфейс на русском, английском и упрощённом китайском.
- Адаптивная панель управления.
- Отдельные контракты будущих инженерных интеграций.

## Запуск

Требуется Node.js 22.12 или новее. Установите зависимости командой `npm install`, затем запустите `npm run dev`.

Для проверки и production-сборки выполните `npm run typecheck` и `npm run build`. GitHub Actions выполняет эти команды автоматически при публикации изменений в main.

## Достоверность и безопасность

Показатели FPS и движение лифта относятся к демонстрационной сцене. Реальная телеметрия здания не подключена. Геометрия использует условные модельные единицы и не является строительной документацией. Интерфейсы энергии, HVAC, воды, отходов, лифтов и безопасности — только контракты будущего подключения. Они не управляют физическим оборудованием.

Физическая реализация потребует профильных специалистов, расчётов, обследования площадки, разрешений и независимой проверки.
