# A-01 X — архитектура

## Назначение

A-01 X — экспериментальная технологическая линия A-01, ориентированная на браузерный цифровой двойник с модульной 3D-сценой. Предыдущие версии остаются архивом и базой инженерных решений.

## Стек

- Three.js — WebGL-сцена, материалы, освещение и камеры.
- TypeScript — типизированная логика приложения и будущих адаптеров.
- Vite — быстрая разработка и production-сборка.
- HTML/CSS — интерфейс поверх 3D-сцены; текст интерфейса не запекается в геометрию.

## Разделение

- `core`: параметры мира, переводы и управление качеством.
- `world`: процедурная геометрия и материалы.
- `reality`: форматы статусов и валидация источников данных.
- `systems`: контракты будущих адаптеров инженерных систем.
- `main.ts`: композиция сцены, событий и цикла рендеринга.

## Координаты

Параметры диаметра, высоты, радиуса атриума и высот уровней централизуются в `src/core/config.ts`. Текущие значения — визуальная компоновка, не размерная документация.

## Дальнейшее развитие

Параметризация всей геометрии купола, отдельные render/collision/navmesh слои, динамическая загрузка секторов, HDRI, управляемые отражения, реальные тесты FPS и интеграция с верифицированными инженерными данными.
