# A-01 X — достоверность Reality View

Каждое отображаемое значение должно иметь явный статус:

- `LIVE` — получено от проверенного физического источника с временными метками.
- `SIM` — вычислено демонстрационной симуляцией.
- `CALC` — результат расчёта по указанной модели и допущениям.
- `DESIGN` — проектное или заданное значение.
- `ILLUSTRATIVE` — только визуальная иллюстрация.
- `STALE` — источник был подключён, но значение устарело.
- `UNKNOWN` — происхождение или качество неизвестно.

Для каждого значения требуются sourceId, единица измерения, observedAt, receivedAt, schemaVersion и оценка качества. Данные плохого качества не могут маркироваться как LIVE.

В v0.1.0 реальная телеметрия не подключена. Показатели FPS описывают текущий браузерный рендеринг; движение лифта — демонстрационная анимация. Они не описывают физическую инфраструктуру.
