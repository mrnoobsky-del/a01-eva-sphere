# A-01 X — стратегия производительности

## Цели

- 60 FPS на современном настольном оборудовании как целевой режим.
- 30–60 FPS на мобильных устройствах в зависимости от GPU и браузера.
- Бюджет кадра: 16,7 мс для 60 FPS; 33,3 мс для 30 FPS.

Это цели для измерения, а не гарантии текущего прототипа.

## Уже заложено

- InstancedMesh для повторяющихся растений и декоративных светильников.
- Профили Low / Medium / High / Ultra.
- Автоматическое понижение качества при устойчивом падении FPS.
- Ограничение pixel ratio и отключение части теней на мобильных устройствах.
- Единый цикл рендеринга и централизованное управление настройками.

## Следующие оптимизации

1. LOD0/LOD1/LOD2 для геометрии на разных дистанциях.
2. Разделение render geometry, collision geometry и navmesh.
3. Подгрузка секторов и уровней по требованию.
4. Frustum и occlusion culling.
5. Атласирование текстур и контроль памяти GPU.
6. Тестовые сцены с фиксированными маршрутами и измерением времени кадра.

## Правило

Сначала измерять на реальных браузерах и устройствах, затем оптимизировать узкое место. Не включать SSR, тяжёлый AO и динамические отражения глобально без доказанной необходимости.
