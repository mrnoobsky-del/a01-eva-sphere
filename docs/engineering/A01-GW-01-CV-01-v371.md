# A-01 v3.7.1 — A01-GW-01 / A01-CV-01 safety refinement

## 1. Purpose
This patch refines the v3.7.0 visual demonstrators. It does not turn them into commissioned systems or approved construction details.

## 2. Gull-wing mutual interlock
The demonstration sequence is now:
1. Confirm the module is isolated and both boundaries are closed.
2. Check conceptual retainers and the manual recovery path.
3. Open the outer access leaf while the inner boundary stays closed.
4. Close and latch the outer leaf.
5. Hold both boundaries closed during the conceptual seal and pressure check.
6. Open the inner boundary only after outer-closed confirmation.
7. Extend and retract the service tray.
8. Close the inner boundary and confirm both boundaries closed.

The visual pose function contains a fail-closed guard: if both open values are non-zero beyond the threshold, it forces both boundaries closed and retracts the tray. This is a software guard in the demo, not a physical interlock.

Real design still requires independent position switches, mechanical locking, pressure monitoring, a hardwired control circuit, trapped-person recovery, manual operation, proof testing and a reviewed failure-mode analysis.

## 3. Crown power-loss scenario
A distinct winter power-loss visual mode has been added and targets a closed crown. This is a design intent, not proof that the crown can close without mains power. A real system needs an independently verified return mechanism or stored-energy source, end-position feedback, icing protection and a manual recovery procedure.

Fire and smoke control must not be subordinated to the ordinary winter or equipment-failure mode. A cause-and-effect matrix must define the priority of fire detection, smoke exhaust, make-up air, fan failure, loss of mains, loss of control power, sensor disagreement and manual override. Critical fire functions need independently designed, code-compliant control and power arrangements.

## 4. Added winter calculation outputs
The calculator now displays estimated natural-draft flow and heat loss for the open-crown winter scenario using the existing simplified equations and inputs from the supplied v3.1.6 prototype. These are scenario indicators only. They do not account for real leakage, wind pressure, louvre discharge coefficients, duct resistance, thermal bridges, icing, CFD, occupancy schedules or applicable code criteria.

## 5. Required engineering work before real-world use
- Structural analysis of the crown, louvres, hinges, actuators, rain hood and wind/snow loads.
- Freeze protection, condensate drainage, de-icing and safe operation during extreme weather.
- HVAC sizing and balancing, outdoor-air hygiene and smoke-control engineering.
- Independent interlocks, emergency power, manual recovery and cause-and-effect testing.
- Accessibility, evacuation, compartmentation and fire strategy review.
- Independent browser and device validation of the digital twin before deployment.

## 6. Validation performed in this patch
- Embedded JavaScript syntax checks.
- HTML ID uniqueness check.
- 1,001 sampled frames of the Gull-wing cycle checked for simultaneous outer/inner opening.
- Closed final state checked.
- No WebGL, browser-device, sensor or hardware commissioning claim is made.
