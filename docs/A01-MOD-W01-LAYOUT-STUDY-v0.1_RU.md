# A01-MOD-W01-LAYOUT-STUDY-01 — варианты планировочной организации санитарного модуля

**Редакция:** 0.1  
**Дата:** 26 ноября 2026 года  
**Spatial ID:** A01-L00-D04  
**Статус:** концептуальное топологическое исследование; не размерный план, не рабочая документация и не подтверждение соответствия.  
**Связанный документ:** [A01-MOD-W01-SANITARY-ENGINEERING-v0.1_RU.md](A01-MOD-W01-SANITARY-ENGINEERING-v0.1_RU.md)

## 1. Назначение и границы

Документ сравнивает две схемы расположения зон санитарного модуля W-01. Он не назначает площадь, размеры, число кабин, сантехнических приборов, ширину проходов, дверные проёмы, диаметры труб или расходы воздуха.

W-01 относится только к санитарным комнатам **A01-L00-D04**. Душевые и раздевальные **A01-L00-D06** остаются отдельным модулем/пакетом и в эти схемы не включены.

Обозначения «передняя сторона», «задняя сторона» и «сервисная сторона» используются только для чтения схем. Они не задают ориентацию здания по сторонам света. Схемы не в масштабе. Показанные функциональные зоны не обязательно должны стать шестью отдельными комнатами.

## 2. Зоны, которые должны быть размещены

| ID | Зона | Планировочная задача |
| --- | --- | --- |
| W01-Z01 | Вход, переход и навигация | Связь с общественным маршрутом L00, понятный выбор направления и экран от прямого обзора кабин |
| W01-Z02 | Умывальники и гигиена рук | Умывание на естественном пути выхода из WC-зоны; без очереди, перекрывающей доступ к другим помещениям |
| W01-Z03 | Стандартные WC-кабины | Приватная зона без прямой видимости из общественного маршрута |
| W01-Z04 | Универсальное доступное санитарное помещение | Самостоятельный безбарьерный подход с общественного маршрута, не через стандартные кабины |
| W01-Z05 | Уборочная / точка персонала | Контролируемое хранение инвентаря и химии, доступ персонала без прохода через пользовательскую зону |
| W01-Z06 | Техническая зона / service spine | Сосредоточение доступных отсечных устройств, стояков и точек обслуживания на согласованной сервисной стороне |

## 3. Вариант A — компактное общее санитарное пространство

**Принцип:** единая входная/распределительная зона. Умывальная зона является общей передней частью стандартного WC-кластера; универсальное помещение имеет отдельный вход непосредственно из входной зоны. Уборочная и технический узел располагаются по сервисному краю.

Схема связей (не масштаб):

```text
                 ОБЩЕСТВЕННЫЙ МАРШРУТ L00
                            |
                            v
       +-------------------------------------------+
       | W01-Z01  ВХОД / НАВИГАЦИЯ / ЭКРАН          |
       |                                           |
       |  отдельный вход                           |
       |       |                                   |
       |       v                 +---------------+ |
       |  +-----------+          | W01-Z02       | |
       |  | W01-Z04   |          | УМЫВАЛЬНИКИ   | |
       |  | УНИВЕРСАЛ.|          +-------+-------+ |
       |  +-----------+                  |         |
       |                                 v         |
       |                        +----------------+ |
       |                        | W01-Z03        | |
       |                        | WC-КЛАСТЕР     | |
       |                        +----------------+ |
       +-------------------------------------------+
                   СЕРВИСНЫЙ КРАЙ / МОКРАЯ СТЕНА
                       +----------+ +------------+
                       | W01-Z05  | | W01-Z06    |
                       | УБОРКА   | | СТОЯКИ /   |
                       |          | | ОТСЕЧЕНИЕ  |
                       +----------+ +------------+
```

**Преимущества для проверки:** компактная композиция; потенциально короткие общие инженерные трассы; меньше внутренних дверей и разделений; простой сценарий ориентации.

**Риски и ограничения:** входная зона и умывальники могут стать местом пересечения потоков; очередь способна блокировать подход к универсальному помещению; стандартный WC-кластер сложнее закрывать и обслуживать независимо от общего пространства; требуется тщательно решить экран приватности и акустико-вентиляционное разделение.

## 4. Вариант B — два самостоятельных пользовательских направления

**Принцип:** из входной зоны пользователь выбирает один из двух самостоятельных маршрутов: универсальное санитарное помещение либо отдельный стандартный WC-кластер. Стандартный кластер получает собственную входную дверь; умывальная зона располагается внутри его пользовательской последовательности. Сервисный край отделён от обоих маршрутов.

Схема связей (не масштаб):

```text
                 ОБЩЕСТВЕННЫЙ МАРШРУТ L00
                            |
                            v
       +-------------------------------------------+
       | W01-Z01  ОБЩИЙ ВХОД / НАВИГАЦИЯ / ЭКРАН    |
       |                                           |
       |  +----------------+   +-----------------+ |
       |  | W01-Z04        |   | ДВЕРЬ WC-КЛАСТЕРА| |
       |  | УНИВЕРСАЛЬНОЕ  |   +--------+--------+ |
       |  | ПОМЕЩЕНИЕ      |            |          |
       |  +----------------+            v          |
       |                         +---------------+ |
       |                         | W01-Z03       | |
       |                         | WC-КАБИНЫ     | |
       |                         +-------+-------+ |
       |                                 |         |
       |                                 v         |
       |                         +---------------+ |
       |                         | W01-Z02       | |
       |                         | УМЫВАЛЬНИКИ   | |
       |                         +---------------+ |
       +-------------------------------------------+
                   СЕРВИСНЫЙ КРАЙ / МОКРАЯ СТЕНА
                       +----------+ +------------+
                       | W01-Z05  | | W01-Z06    |
                       | УБОРКА   | | СТОЯКИ /   |
                       |          | | ОТСЕЧЕНИЕ  |
                       +----------+ +------------+
```

**Преимущества для проверки:** два понятных независимых направления; стандартный кластер можно закрывать, убирать и обслуживать отдельно; доступ к универсальному помещению не проходит через очередь у умывальников; проще организовать самостоятельный режим работы каждой части.

**Риски и ограничения:** больше дверей и перегородок; может потребоваться большая площадь; надо проверить, не создают ли двери встречные конфликты, узкие места и лишние повороты; инженерные трассы могут оказаться длиннее; необходимо подтвердить, что умывальники не блокируют выход из WC-кабин и общий маршрут.

## 5. Сравнение вариантов

| Критерий | Вариант A — общее пространство | Вариант B — два направления |
| --- | --- | --- |
| Компактность | Потенциально выше | Потенциально ниже |
| Разделение потоков | Требует сильного решения входной зоны | Потенциально понятнее |
| Независимое закрытие стандартного WC-кластера | Ограничено общей композицией | Проще предусмотреть |
| Доступ к универсальному помещению | Отдельный вход из общего пространства | Отдельная ветвь от входной зоны |
| Уборка и эксплуатация | Требует согласования с общественным потоком | Можно организовать более независимо |
| Количество дверей/перегородок | Потенциально меньше | Потенциально больше |
| Риск очередей | Вход и умывальники могут конфликтовать | Очереди легче локализовать, но узкие места всё равно требуют расчёта |
| Инженерная компактность | Потенциально лучше при общей мокрой стене | Зависит от фактической геометрии стояков |

Сравнение качественное. Это не балльная оценка и не расчёт пропускной способности.

## 6. Предварительная рабочая рекомендация

Для следующей проверки принять **вариант B как основной сценарий планировочной проработки**, а вариант A сохранить как компактную альтернативу.

Причина выбора B на текущем этапе — более явное разделение универсального помещения, стандартного WC-кластера и эксплуатационного доступа. Это снижает вероятность того, что очередь к общим умывальникам заблокирует безбарьерный подход или что закрытие одной части автоматически остановит всю санитарную зону.

Это **не окончательное решение**. Если фактическая площадь или геометрия помещения не позволяют реализовать B без ухудшения доступности и эвакуации, нужно вернуться к A или разработать третью схему. Нельзя уменьшать нормативные проходы или маневровые зоны ради сохранения выбранной композиции.

## 7. Обязательные правила соседства и потоков

1. **Z01:** из общественного атриума/коридора не должно быть прямого обзора WC-кабин. Навигация читается до входа, но не раскрывает приватную часть.
2. **Z02 ↔ Z03:** умывальники связаны с маршрутом пользователей WC-кластерa; после кабины не требуется проходить через уборочную или пересекать служебный маршрут.
3. **Z04:** доступен непосредственно с общественного безбарьерного маршрута. Не размещать его за стандартными кабинами, турникетом, запираемой общей дверью или зоной очереди.
4. **Z05:** доступ персонала и хранение химии контролируются. Уборочная не является проходом к WC или техническим стоякам.
5. **Z06:** запорная арматура, счётчики, прочистки и обслуживаемые узлы доступны без демонтажа постоянной отделки и без входа в приватную кабину.
6. Посетительский маршрут и сервисный маршрут не должны пересекаться там, где это можно избежать. Уборка во время работы требует отдельного сценария ограждения и временного обхода.
7. Вызов помощи из Z04 должен иметь локальную работоспособность, понятную индикацию и доставку в реально обслуживаемую точку. Облако, телефон, Ева или Орион не являются единственным каналом.
8. Уборочная мойка, трап, насос, отдельный вентилятор и дополнительные технические шкафы не закладываются автоматически: каждый элемент подтверждается эксплуатацией и расчётом.

## 8. Что требуется до размерного плана

| Входные данные | Что они определяют |
| --- | --- |
| Обмерный/проектный контур помещения, высоты, колонны и несущие элементы | Реальная геометрия и доступная площадь |
| Точное положение общественного входа, дверей, коридоров и эвакуационных путей | Подходы, выходы и конфликт дверей |
| Положение водопроводных и канализационных стояков, отметки выпуска | Реальная мокрая стена и возможность самотёка |
| Доступные точки вытяжки/притока и пожарные границы | HVAC-маршрут и режимы при пожаре |
| Ожидаемая посещаемость по часам, пиковые события, штат персонала | Количество и типы приборов, пропускная способность |
| Требования к семейному использованию, приватности, персоналу и доступным помещениям | Состав санитарной программы |
| Применимая нормативная матрица и проверка специалистом по доступности | Проверяемые габариты, зоны маневрирования и оборудование |

Пока этих данных нет, не назначать число кабин, ширины проходов, радиусы разворота, уклоны, высоты, диаметры труб или производительность вытяжки.

## 9. Следующий выпуск после получения геометрии

1. Нанести выбранную схему на фактический контур с осями, дверями и существующими конструкциями.
2. Проверить безбарьерный маршрут, маневрирование и зоны открывания дверей.
3. Определить требуемый состав и число приборов на основании расчётной посещаемости и применимых норм.
4. Разместить стояки и доступные сервисные панели; показать воду, канализацию, вентиляцию, электрику и пожарные интерфейсы.
5. Выпустить координационные планы, разрезы мокрых узлов, ведомость оборудования и расчётные нагрузки.
6. Зафиксировать проверки, замечания и доказательства по статусам A-01 Sphere Standard.

## 10. Статус

**W-01 остаётся M0 / proposed / not calculated.** Выпущено только исследование двух топологических вариантов. Размерный план, расчёты, подбор изделий, нормативная проверка и согласование специалистами не выполнены.
