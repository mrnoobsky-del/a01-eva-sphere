# Сферы сообщества A-01

Здесь размещаются самостоятельные проекты Сфер, которые предлагают участники сообщества. Цель — совместимая архитектурная платформа, которую разные команды могут адаптировать под собственную площадку, климат, размеры и потребности.

## Как добавить Сферу
1. Скопируйте `template/` в `spheres/<уникальный-id>/`.
2. Заполните `sphere.json` и добавьте README с описанием идеи, команды, источников и открытых вопросов.
3. Не выдумывайте размеры, нагрузки, разрешения и эксплуатационные показатели. Неизвестное оставляйте `null` или помечайте как предварительное.
4. Отправьте pull request с названием `Add community Sphere: <id>`.

У каждой Сферы должны быть собственный паспорт, версия, перечень систем и список источников. Реестр не подтверждает, что проект построен, сертифицирован или одобрен как безопасный. Участники сохраняют авторство своего вклада. До появления лицензии правила повторного использования кода, моделей и изображений остаются не определены.
