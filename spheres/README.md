# Community Spheres

This directory is a lightweight registry for independent Sphere proposals and community projects. Copy `template/` to `spheres/<sphere-id>/`, complete the manifest, add a README and submit a pull request.

Each project has its own ID, status, geometry, systems, contributors, evidence and open questions. Keep unknown values null or clearly marked as proposed. Registry inclusion does not imply construction, certification, ownership by A-01 or endorsement.

The digital-twin viewer does not yet dynamically load community manifests. This registry and template are the first step toward a future multi-Sphere catalogue and shared configuration format.


## Reference project

- [A-01 — The Sphere of Eva](a01/sphere.json) — origin project and example manifest.

Read the [A-01 Sphere Standard](../standards/A01-SPHERE-STANDARD-v0.1.md) and use the [manifest schema](../schemas/sphere-manifest.schema.json) for new proposals. Community Spheres are separate projects. The 3D viewer does not yet load arbitrary manifests at runtime.
