# EvaScribe — локальная медиатека и видеоисследования

**Версия:** 0.1.0 · **Стадия:** рабочий локальный MVP / предварительная версия.

EvaScribe превращает аудио и видео в библиотеку материалов с транскриптами, таймкодами, поиском и экспортом. Приложение рассчитано на локальный запуск в Windows и открывается в браузере.

## Что уже работает в MVP

- загрузка локальных видео- и аудиофайлов;
- добавление публичных YouTube URL через `yt-dlp` (только HTTPS и домены из allowlist);
- получение доступных русских/английских субтитров WebVTT прежде, чем запускать распознавание;
- локальная транскрибация через `faster-whisper`, CPU / `int8` по умолчанию;
- очередь с этапом, прогрессом и состоянием задачи; незавершённая работа возвращается в очередь после перезапуска;
- локальная SQLite-медиатека и полнотекстовый поиск;
- плеер с перемоткой по таймкодам, когда сохранён медиафайл;
- поиск совпадающих фрагментов по вопросу; при подключённом OpenAI-compatible LLM endpoint — ответ по транскрипту с требованием ссылок на таймкоды;
- экспорт TXT, Markdown, JSON, SRT и VTT;
- удаление материала и связанных локальных файлов;
- адаптивный интерфейс, светлая/тёмная тема.

## Требования

- Windows 10/11 x64;
- Python 3.11 x64;
- интернет для установки зависимостей и первоначальной загрузки модели Whisper;
- свободное место для медиафайлов и моделей.

GPU пока не включается автоматически: базовый профиль безопасно запускается на CPU. При наличии совместимой NVIDIA GPU параметры можно менять вручную после отдельной проверки CUDA/CTranslate2.

## Установка и запуск

1. Скачайте каталог `tools/evascribe` из репозитория A-01.
2. Установите Python 3.11 x64 с [python.org](https://www.python.org/downloads/windows/).
3. Откройте PowerShell в каталоге `tools/evascribe`.
4. Выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\install-and-start.ps1
```

При следующих запусках достаточно:

```powershell
.\scripts\start.ps1
```

После сообщения о запуске откройте `http://127.0.0.1:8765` в браузере. Чтобы остановить приложение, нажмите `Ctrl+C` в окне PowerShell.

При первой обработке faster-whisper скачает выбранную модель в локальный каталог данных. По умолчанию используется модель `base` на CPU с `int8`. Название модели можно изменить в `.env` (`EVASCRIBE_MODEL=small`, например), учитывая скорость и память конкретного компьютера.

## Где хранятся данные

По умолчанию Windows:

`%LOCALAPPDATA%\EvaScribe\`

- `evascribe.sqlite3` — библиотека и сегменты транскриптов;
- `media\` — исходные загруженные/полученные медиафайлы;
- `models\` — локальные модели распознавания.

Каталог можно перенести через `EVASCRIBE_DATA_DIR` в `.env`. Резервную копию рекомендуется делать при остановленном приложении, копируя весь каталог данных.

## Настройка LLM (необязательно)

Без LLM приложение всё равно создаёт транскрипт, черновой экстрактивный обзор, ключевые слова и поисковые совпадения. Это не называется AI-резюме и не считается проверкой фактов.

Для локального провайдера, совместимого с OpenAI Chat Completions API, заполните `.env`, например:

```dotenv
EVASCRIBE_LLM_BASE_URL=http://127.0.0.1:11434/v1
EVASCRIBE_LLM_MODEL=имя-установленной-модели
EVASCRIBE_LLM_API_KEY=
```

После изменения `.env` перезапустите приложение. Ключи не добавляйте в GitHub.

## Ограничения MVP

- API и интерфейс доступны только через `127.0.0.1`; не публикуйте порт в локальную сеть или интернет.
- URL-импорт ограничен доменами из `EVASCRIBE_ALLOWED_HOSTS`; по умолчанию это YouTube.
- Извлечение медиа не обходит DRM, платный доступ, авторизацию или другие ограничения платформ. Используйте только источники, которые вы вправе обрабатывать.
- Субтитры могут отсутствовать или быть неточными. При их отсутствии запускается ASR.
- Сейчас не реализованы diarization, OCR кадров, пакетный импорт каналов, пользовательские аккаунты, синхронизация, MCP-сервер и автоматическая отправка в Notion/GitHub.
- Без LLM вопросы обрабатываются текстовым поиском, а не семантическим анализом.
- AI-ответы и транскрипты могут ошибаться; существенные выводы следует сверять с оригинальным видео и независимыми источниками.

## Архитектура

- FastAPI + Uvicorn;
- SQLite + FTS5;
- faster-whisper / CTranslate2;
- yt-dlp для ограниченного импорта URL;
- WebVTT parser для уже имеющихся субтитров;
- HTML/CSS/JavaScript без внешних UI/CDN-зависимостей.
