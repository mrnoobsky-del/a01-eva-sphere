# A-01 v3.3.0 — 伊娃之球离线数字孪生架构

**状态：** 架构规范与实施计划。本文档不表示完整离线版本已经发布，也不表示其已通过验收。

## 目标

A-01 数字孪生应在完全没有外部网络的情况下保持可用。网络连接只能扩展功能，不应成为启动 3D 场景、浏览模型、查看对象或阅读项目资料的前提。

主要使用场景：先断开网络，双击一个 HTML 文件，打开 A-01 数字球体，查看并浏览模型，使用本地参考资料，并导出可用的本地数据。

## 离线核心要求

1. 通过 file:// 启动，无需本地服务器、BAT 启动脚本、CDN 或外部 JavaScript 模块。
2. 保留当前 3D 场景、摄像机控制、导航、自适应界面和沉浸式对象查看模式。
3. 包含本地对象注册表、楼层/区域、工程资料及必需媒体资源。
4. 显示真实的离线状态；可选服务不可用时应平稳降级。
5. 本地数据与服务器同步、云端专属功能明确分离。
6. 构建过程可重复，并提供资源清单、第三方声明、哈希值和验收证据。

## 架构分层

### A-01 CORE

本地运行时、界面、3D 引擎、摄像机与输入、对象注册表、本地数据模型、帮助、设置和诊断。

### World Runtime

人物/伙伴模块、移动、对象交互、本地 Eva 行为及其他可选智能体。每个模块必须有明确的启动契约；可选智能体失败不得阻止基础场景加载。

### Local Knowledge

内置对象说明、楼层、工程子系统、操作流程及本地搜索/导航。外部链接必须标明需要网络。仅在许可和版本来源明确时，才可加入第三方文件的本地副本。

### Local Data

设置、笔记、选中对象、本地任务和可导出的状态快照。不同浏览器对 file:// 下的 localStorage/IndexedDB 支持并不一致，不能假设其行为统一。启动时应探测存储能力、验证实际写入、显示真实保存状态，并提供 JSON 导出/导入。未经确认不得提示保存成功。

### Online Adapter

为 Cloudflare Worker/Eva 服务、同步、更新及外部服务提供独立网络适配层。所有网络操作都必须有超时、错误处理和离线回退。未经用户明确操作，不得上传本地用户数据。

### Optional Local AI

可选的设备端语言模型模块。它不属于最小 HTML 核心：模型权重、计算资源和本地推理运行时是独立交付项。基础离线模式可以提供本地知识检索和确定性助手功能，但不得假装云端 LLM 正在本地运行。

## 交付形式

### 1. Single HTML Offline

主要目标。在构建阶段，将源 ES 模块（包括 Three.js 和必要控制器）编译成一个自包含 JavaScript bundle，不保留外部运行时导入，并将其嵌入 HTML。必需静态资源应作为 data URL/内嵌数据加入，或通过程序生成。构建检查必须列出并拒绝任何剩余的必需外部文件。

CDN import map 或 vendor 相对路径本身不等于经过验证的单文件离线版本。验收要求没有任何必需网络请求。

### 2. Portable Offline Pack

另行提供压缩包，包含 HTML、本地库、媒体、文档、许可证、资源清单和验证启动器。如果浏览器限制或资源体积导致双击启动不可靠，压缩包可以提供本地服务器作为替代启动方式。但这不能替代 Single HTML 验收。

### 3. PWA / Hosted Offline

单独的 HTTPS 部署版本，使用 Service Worker 和离线缓存。Service Worker 属于托管的安全 origin，不能作为 file:// 本地 HTML 的启动机制。PWA 是额外分发渠道，不替代独立 HTML。

## 构建与模块要求

- 内嵌运行时不得执行网络导入。
- 固定所有依赖版本，并随包提供许可证和声明。
- 扫描 HTML、CSS 和 JavaScript 中的 script/module src、CSS url()、纹理/模型/字体/音频加载器、fetch()、XHR、WebSocket、Worker 和动态导入。
- 网络集成只能是可选功能，不得阻塞核心启动。
- WebGL 缺失时显示明确的能力诊断，不应误报 CDN 或引擎下载错误。
- 可选模块失败不得停止主界面。
- 提供版本清单、构建资源 SHA-256 和第三方许可证报告。

## 离线/在线能力矩阵

| 功能 | 离线 | 在线 |
|---|---|---|
| 3D 场景和摄像机 | 支持 | 支持 |
| 导航与对象查看 | 支持 | 支持 |
| 内置知识库 | 支持 | 支持 |
| 本地设置与导出 | 取决于存储探测 | 支持 |
| 云端 Eva 聊天 | 不支持 | 支持 |
| 服务器同步 | 不支持，变更保留本地 | 经用户同意 |
| 本地 LLM | 需单独安装 | 可选 |
| 外部链接/服务 | 不支持 | 支持 |

## 数据持久化与同步

1. 启动时探测 localStorage、IndexedDB 及真实读写能力。
2. 显示准确状态：持久化可用、仅支持导出或存储不可用。
3. 提供 JSON 导入/导出，并验证 schema 和版本。
4. 网络同步必须是独立的用户操作。
5. 迁移或同步前创建备份。
6. 不得静默覆盖冲突；应提供冲突处理或保留两个版本。

## 安全

- 不得在 HTML 中嵌入秘密、API 密钥或私有令牌。
- 不得自动上传笔记、历史记录或任务。
- 外部操作和链接必须标明需要网络。
- 按 schema、大小限制和允许字段验证导入的 JSON。
- 本地资源优先使用固定且可验证的构建产物。
- 随包提供第三方声明和源许可证。

## 实施阶段

**阶段 0 — 基线：** 固定源版本，盘点导入项、资源和功能，记录体积与哈希。

**阶段 1 — 依赖审计：** 扫描 HTML/CSS/JS 中的 URL、import、src/href、CSS url()、fetch、XHR、WebSocket、Worker、字体、图片、模型、音频和视频。

**阶段 2 — Bundle：** 建立可重复的构建流程并固定工具链和依赖，生成无运行时外部导入的自包含 bundle。

**阶段 3 — 资源封装：** 内嵌所有必需资源，并移除阻塞式网络加载器。

**阶段 4 — 本地数据：** 实现能力探测、保存状态、JSON 导入/导出及 schema 版本控制。

**阶段 5 — 网络隔离：** 将服务器功能移入 Online Adapter，并验证离线降级。

**阶段 6 — 验收：** 在真实 Chromium/Edge 和 Firefox 中测试，包括断网后的首次启动和干净浏览器配置。

**阶段 7 — Portable/PWA：** 构建备用压缩包，并单独编写 HTTPS/PWA 部署说明。

## Single HTML 验收标准

- 在网络已断开的情况下，双击文件即可打开。
- DevTools Network 中没有必需 HTTP(S) 请求；可选网络功能失败时应平稳降级并明确提示。
- 3D 场景正常渲染，不出现“无法加载 3D 引擎”。
- 摄像机、导航、楼层选择、对象查看和界面恢复正常。
- 桌面端展开侧栏时，中央视口应缩小，而不是被覆盖。
- 不存在由缺失模块或资源导致的 JS 错误。
- 测试 WebGL 可用性以及 WebGL 不可用时的行为。
- 关闭并重新打开文件后测试持久化；若浏览器无法提供稳定存储，界面必须提供导出。
- 交付物包含版本、SHA-256、依赖清单和许可证声明。
- 验收证据记录浏览器、操作系统、日期和实际网络日志。

## 测试矩阵

至少测试：
- Windows 上的 Chrome/Chromium 和 Edge；
- Windows 上的 Firefox；
- Linux 上的 Chromium；
- macOS 当前桌面浏览器；
- 单独测试移动 Safari/Chrome，因为本地文件访问和持久化存在额外平台限制。

每项结果必须标记为 **PASS**、**FAIL** 或 **NOT TESTED**。静态代码检查不能证明浏览器中的视觉运行成功。
