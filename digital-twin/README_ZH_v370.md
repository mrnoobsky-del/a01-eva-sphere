## 1. 更新内容

v3.7.0 保留 v3.6.0 原始场景，并在主导航中增加 **“舒适”** 入口，在 A-01 工作区中打开嵌入式 Human Comfort Engineering 工程页面。

工作区整合六个主题：无台阶交通；通用卫生间和淋浴；家庭照护室；给水及分流排水；楼层结构、天花和设备夹层；无障碍疏散与求助。

## 2. 交互示意图

模块提供 L00–L04 楼层选择和楼层说明，并可切换无障碍路线、电梯核心、自动扶梯、污水立管及供水图层。六个内容区为 Access、Sanitary、Family、Water、Floors 和 Evacuation。俄语/英语与浅色/深色主题会和主应用同步。

垂直剖面是响应式 SVG 系统关系图，不是按比例建筑图纸或几何 3D 模型。自动扶梯仅作为辅助交通；无台阶垂直通行依赖电梯和连续无障碍路线。

## 3. 设计逻辑

**无障碍。** 从场地和入口到公共及居住功能形成连续路线。电梯是主要垂直交通方式。自动扶梯和楼梯不能替代无障碍路线。导向结合视觉、触觉和声音信息。

**卫生空间。** 通用卫生间、无障碍淋浴、扶手、求助呼叫、易清洁饰面、靠近异味源的局部排风，以及门、隔墙、污水立管和通风的声学保护。

**家庭照护。** 设置安全换尿布台、婴儿车空间、喂养座椅、母乳喂养及吸奶私密空间、洗手盆、卫生用品和安全加热设备。家庭照护室不能替代公共无障碍卫生间。

**给水与污水。** 分开饮用水、灰水、黑水、雨水/融雪水、厨房排水及技术排水。考虑淋浴废水热回收、漏水保护、清扫口和维护空间。灰水回用必须经过独立处理、质量监测，并防止饮用水网络倒流污染。

**楼层与天花。** 保留原始球体的雕塑曲面檐带和隐藏灯光。结构楼板、梁、隔声层、设备夹层、防火分隔及建筑天花是相互协调的独立层。装饰面不能替代结构或防火构造。

**疏散。** 普通自动扶梯和客梯不会自动成为疏散设施。需要专门消防策略、符合规范的防护区域与路线、无障碍报警、双向通信、工作人员、备用电源和实地演练。

## 5. 验证与限制

**已完成：** 基于 v3.6.0 创建独立 v3.7.0 文件，未覆盖旧版；在主导航增加“舒适”入口并接入集成页面机制；添加五层选择、交互 SVG 示意图、系统图层、六个分区、俄英切换及主题同步。

**尚未完成：** 在真实 Three.js/WebGL 场景中完整浏览；实体设备、屏幕阅读器和真实用户测试；将卫生设备、自动扶梯和管道作为 Three.js 实体加入空间模型；米制校准；电梯客流、路线、管道、排水坡度、通风、声学、防火分区及疏散计算；BIM/IFC、P&ID 或真实自动化连接。

新工作区作为独立工程页面嵌入应用，垂直剖面是交互式 2D 示意图，不是新的 3D 几何。发布 GitHub 文件不会自动更新 uCoz 网站。主场景保留 v3.6.0 的视觉语言；v3.7.0 不代表实体建筑已建成或符合规范。

## 6. 后续工程关口
1. 协调 L00–L04 尺寸平面、人数和功能分区。
2. 布置无障碍卫生间及家庭照护室，检查净尺寸和路线。
3. 计算电梯交通并审查自动扶梯、楼梯和平台。
4. 建立楼板、设备井、给排水和 HVAC 协调 BIM/IFC。
5. 计算水量平衡、排水坡度与能力、卫生通气、局部排风、噪声和热回收。
6. 与合格专家和用户代表制定消防及疏散方案。
7. 完成独立无障碍审计和用户测试。
