# A-01 v3.1.9 — 全屏对象研究模式

**基线：** 主网站版本 v3.1.6，以及准备好的 v3.1.7、v3.1.8 主线集成。

## 功能
- 点击 3D 模型对象或选择“Изучить объект”即可进入独立的全屏研究模式。
- 摄像机聚焦所选对象。桌面端将对象安排在信息卡片左侧；手机端信息卡片位于屏幕底部。
- 主导航、上下文面板、场景标签和常规控制暂时隐藏。
- 信息卡片覆盖在 3D 场景上，显示对象描述、楼层、ID、概念设备及关联系统/区域。
- 点击关闭按钮或按 Escape 恢复界面；进入研究前打开的上下文面板会恢复原状态。
- 研究期间暂停背景对象选择和自由飞行移动，关闭卡片后恢复。
