# A-01 Asset Lab v0.1

**Путь:** `digital-twin/a01-asset-lab.html`  
**Статус:** автономный инструмент для локальной инспекции 3D-моделей  
**Версия Three.js:** 0.185.0

## Назначение

Asset Lab позволяет предварительно проверять внешний glTF/GLB-ассет перед тем, как принимать решение о его включении в цифровой двойник A-01. Инструмент отделён от основной сцены: он не меняет v4.9.4 и PBR preview v4.9.5.

## Возможности

- импорт одного бинарного файла `.glb`;
- импорт `.gltf` вместе с ресурсами из выбранной папки (папка должна быть предварительно распакована);
- изолированная Three.js-сцена с орбитальной камерой без авто-вращения;
- PBR-окружение на основе RoomEnvironment / PMREM;
- оценка количества треугольников, вершин, mesh, материалов, текстур и анимационных клипов;
- оценка габаритов исходной модели и нормализация её масштаба только для просмотра;
- каркасный режим, сетка, уровень пола и воспроизведение клипов;
- экспорт локального JSON-отчёта с атрибуцией и результатами инспекции.

## Как использовать

1. Откройте страницу Asset Lab.
2. Скачайте выбранную модель со страницы автора в соответствии с текущими условиями Sketchfab.
3. Для бинарной модели выберите файл `.glb`.
4. Если скачан архив с `.gltf`, `.bin` и текстурами, распакуйте архив на устройстве, затем выберите **GLTF + папка** и укажите эту папку.
5. После загрузки изучите статистику, материалы и анимации.
6. Заполните автора, ссылку на исходную страницу, точную лицензию и изменения.
7. Экспортируйте JSON-отчёт и сохраните его в материалах аудита ассета.
8. Проверьте файл по [A-01 Asset Report Schema v0.1](../schemas/a01-asset-report-v0.1.schema.json).

## Локальная обработка и приватность

Модель читается локально в браузере. Файлы не передаются на сервер A-01, Wix или GitHub. Инструмент не содержит Sketchfab OAuth, не запрашивает приватный токен и не скачивает модели через Sketchfab Download API.

Для Sketchfab Download API требуется аутентификация пользователя. Нельзя подменять её прямыми ссылками или общими токенами. См. [официальную документацию Sketchfab Download API](https://sketchfab.com/developers/download-api).

## Ограничения v0.1

- максимальный размер набора файлов — 150 МБ;
- GLB и папка glTF поддерживаются, архив ZIP непосредственно не распаковывается;
- Draco и Meshopt декодеры не подключены; сжатые модели могут не открыться;
- проверка лицензии автоматизированно не выполняется;
- счётчик геометрии предназначен для первичной оценки; он не заменяет GPU-профилирование draw calls и frame-time;
- мобильная и браузерная приёмка должна выполняться отдельно на целевых устройствах;
- модель в лаборатории не считается интегрированной в A-01 и не подтверждает её инженерную пригодность.

## Производительность и безопасность

- один цикл рендеринга принадлежит отдельной странице Asset Lab;
- импортированные файлы не запускаются как произвольный код;
- внешние URL-ресурсы glTF должны быть представлены файлами в выбранной локальной папке;
- при удалении модели геометрии, материалы и текстуры освобождаются;
- не загружайте закрытые, конфиденциальные или нелицензированные модели.

## План следующего этапа

1. Провести браузерную проверку обеих загруженных моделей в отдельной Asset Test Scene.
2. Проверить WebGL, ориентацию, клиппинг, материалы, работу анимации робота и освобождение ресурсов.
3. Выполнить desktop/mobile приёмку и записать frame-time p50/p95, draw calls и время загрузки.
4. Повторно проверить страницы источников и условия CC BY перед любым публичным повторным распространением.
5. Только после успешной приёмки рассмотреть интеграцию через отдельный адаптер; основную сцену v4.9.4 не менять.

Связанный документ: [Реестр 3D-ассетов и план интеграции](../docs/A01-SKETCHFAB-ASSET-AND-IMPLEMENTATION-REGISTER-v0.1_RU.md).

### Как получить исходный файл

Официальная документация Sketchfab Download API требует аутентифицированного пользователя. В текущем процессе автоматическая загрузка не используется. Откройте исходную страницу, войдите в собственную учётную запись Sketchfab при необходимости и используйте штатный Download. Сохраните GLB или распакуйте архив glTF. Не передавайте пароль, токен или cookies в чат.

### Первое тестирование

1. В Asset Lab выбрать GLB; или распаковать ZIP и выбрать папку с `.gltf`, `.bin` и текстурами.
2. Заполнить карточку: title = Delivery robot; author = Bento (@gostbento), creator description requests credit to Eric; source URL — ссылка выше; license = CC BY 4.0; changes = not modified (until changes are made).
3. Экспортировать JSON и проверить его по [A-01 Asset Report Schema](../schemas/a01-asset-report-v0.1.schema.json).
4. Сначала сохранить исходный GLB отдельно. Не перезаписывать исходник при оптимизации.
5. После проверки сделать неразрушающие копии: оригинал высокого качества, runtime-копия и упрощённая статическая LOD-копия только для частей, которые не деформируются скелетом.
6. Не упрощать skinned mesh и кости без отдельной проверки rig/weight data и теста анимационных клипов. Для первого прохода достаточно ограничить текстуры, удалить лишние материалы, проверить draw calls и подготовить статические LOD для жёстких деталей, если они есть.
7. Проверить поведение на desktop и телефоне. Фиксировать frame-time p50/p95, draw calls, texture memory proxy, загрузку и переключение LOD.

**Статус по состоянию на 28.11.2026:** пользовательский GLB получен и структурно проверен офлайн. Созданы JSON-отчёт и отдельная runtime-копия. Браузерная, мобильная и GPU-приёмка ещё не выполнены; интеграции в основную сцену нет.
