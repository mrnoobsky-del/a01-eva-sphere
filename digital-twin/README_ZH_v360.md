## 2. 3D 设备布局

模型将设备分为独立的可视化组。

### 外部资源工厂
- 月壤进料斗和封闭进料路径
- 高温熔融月壤电解（MRE）反应器
- 含金属残渣容器
- 初级气体调质柱
- 双重边界产品传输接口

### 洁净 ECLSS 设备
- 水处理模块
- 水电解槽与电池组示意
- CO₂ 吸附床及切换阀
- 空气循环与精细过滤模块
- 气体成分分析仪
- Sabatier 反应器示意

### 储存与分配
- 两个 O₂ 缓冲储罐
- 初始惰性气体库存储罐（作为需要运送的初始库存显示；不假设月球本地氮源）
- H₂ 工艺缓冲罐
- 水缓冲罐
- O₂、CO₂ 回流和水的独立立管
- 沿概念楼层 L00–L04 的环形分配路径

工业 MRE 区域在视觉上与栖居舱洁净生命保障区分离。产品气体先经过调质和传输边界，再进入洁净侧缓冲储罐。

## 3. 交互显示模式

AIR-01 面板提供四种显示模式：

| 模式 | 显示内容 |
|---|---|
| 完整循环 | 外部 MRE、洁净 ECLSS、储存和分配 |
| O₂ 生产 | 月壤处理、气体调质、水电解和氧气储存 |
| 空气恢复 | CO₂ 捕集、Sabatier 支路、水与氧气循环 |
| 备用 · MRE 停机 | 视觉隔离外部生产线，同时显示洁净侧储备与空气净化概念 |

这些模式只控制场景对象的可见性。选择器不控制设备、不模拟化学动力学、不计算流量，也不能证明应急程序有效。

动画点仅表示概念流向。它们不是气体粒子、遥测数据、测量流量或压力读数。

## 4. 面板中的参考计算

面板显示 AIR-01 概念说明中的四人初步规划情景：

| 参数 | 规划值 |
|---|---:|
| O₂ 需求 | 3.36 kg/天 |
| CO₂ 生成 | 4.00 kg/天 |
| 理想 O₂ 水电解进水量 | 3.78 kg/天 |
| 理想 H₂ 副产量 | 0.42 kg/天 |
| 使用该 H₂ 时 Sabatier 理想处理的 CO₂ | 2.31 kg/天 |
| 理想平衡中剩余的 CO₂ | 1.69 kg/天 |

这里故意保留了非零的 CO₂ 剩余量。界面不应暗示碳或氧循环已经完全闭合。

MRE 参考值来自 NASA 地面演示：处理 25 kg 月壤模拟物，平均产氧速率 0.07 kg O₂/小时，在相关真空条件下运行九小时。面板将 0.14 kg/小时标为在假设连续运行 24 小时的情况下达到 3.36 kg/天所需的简单平均速率。这只是算术比较，并非已演示的连续产量或月面运行额定值。

## 6. 验证与限制

### 本次软件迭代已完成
- 将 AIR-01 注册到场景对象列表。
- 添加 3D 概念设备及独立分配管线组。
- 添加显示模式、导航、搜索入口和对象详情。
- 将 AIR-01 状态加入场景 API 状态快照。
- 将 HTML 版本元数据更新为 v3.6.0。
- 集成后对所有内嵌 JavaScript 块（普通脚本和模块脚本）进行了语法检查。

### 尚未完成
- 在真实浏览器/WebGL 中漫游托管的 v3.6.0 模型。
- 在目标手机和桌面设备上进行视觉检查。
- 将对象比例校准到实际米制尺寸。
- 管径、压降、阀门选型、储罐容积或压力容器设计。
- 功率、热量、结构、辐射、大气成分或乘员安全计算。
- 气体纯度测试、设备鉴定、容错演示或自主控制。

当前环境中的浏览器无法联网获取该分支文件，因此未能启动真实 WebGL 场景。当前模型已完成源代码和语法检查，但尚未通过视觉验收。

所有场景单位与几何比例仍未校准。3D 管道半径仅用于视觉表达，不代表管道尺寸。该模型不是 P&ID、施工设计、实际运行的 ECLSS、飞行鉴定硬件或安全论证。没有连接真实传感器、遥测、阀门、反应器、压缩机或生命保障设备。

## 7. 后续工程关口

1. 校准场景参考几何并定义月面安装边界。
2. 明确任务、乘员剖面、大气概念和惰性气体库存。
3. 基于可追溯的子系统数据建立部件级质量、功率和热量预算。
4. 确定 MRE 产品气体杂质限值，以及脏区/洁净区接口的验收门槛。
5. 闭合 CO₂、氢气、水、甲烷和氧气的物质平衡，或明确剩余废物流。
6. 制定故障树、独立安全控制和储备时长依据。
7. 邀请 ECLSS、化学工艺、压力系统、热控、电力、消防和人因领域的合格专家进行审查。
