# A-01 v3.6.0-rc1 — 分层围护、主框架与三语言工作空间

**状态：** 位于 release/a01-v360-architecture-i18n-rc1 分支的候选版本。尚未合并到 main，也未部署到公开的 uCoz 网站。

## 本版本变更

- 增加概念主框架：24 根竖向支柱、五道外环梁和五道中庭环梁、径向楼层梁、24 根屋面支撑柱、24 根屋面肋、屋面弹簧环和顶部节点。
- 修复分布式扬声器的楼层坐标问题：扬声器属于各自楼层组，垂直坐标现在使用楼层局部坐标，不再重复叠加楼层标高。
- 调整服务机器人和伊娃导览标记，使其贴近地面；修正绿色模块中小树的底部位置。
- 在内外视图中隐藏透明半球。内部 144 片 LED 数字天幕与外部不透明的 144 片天气围护面板分别呈现。
- 增加两条环形通行带的黄金比例研究，并小幅调整中庭半径。
- 新增包含 598 条记录的几何组件护照登记册。
- 增加俄语、英语和简体中文界面词典，支持浏览器语言自动检测和手动选择保存。

## 模型的四个层次

模型区分：主结构 STR、内部环境与生命安全边界 ENV、可更换外部面板 CAS、内部数字天幕与体验层 SKY。内部 LED 天幕并不是室外天空；外部天气面板也不是透明玻璃。

连续的内部空气、水、蒸汽、热工和消防边界仍属于独立工程系统，其实体构造尚未确定。

## 语言行为

- 自动模式检查 navigator.languages，支持俄语 ru、英语 en 和简体中文 zh-CN。
- 手动选择保存在设备本地的 localStorage 中。
- 界面词典在本地运行，不会把用户输入发送到外部翻译服务。
- 不应宣称嵌入式长篇项目文档已经全部机器翻译。请使用下面的语言专用 README 阅读完整说明。

## 几何与工程数据

场景坐标尚未校准为米。组件护照登记几何量和设计意图中的支撑关联；物理属性仍为空或 TBD：质量、材料牌号、截面、紧固件、风雪作用、刚度、连接承载力和专业验证。

渲染模型中的数字不会自动成为工程计算。概念框架用于展示预期的荷载传递路径，不代表已证明承载能力或符合规范。

## 黄金比例研究

两条环形通行带采用无量纲黄金比例：

- 内侧通行带：1.40768957 模型单位。
- 外侧通行带：0.87 模型单位。
- 比值：1.61803399…（φ）。

这只是建筑空间比例，不是疏散通道宽度或安全判据。详见 [A01-GOLDEN-SECTION-STUDY-v0.1](../architecture/A01-GOLDEN-SECTION-STUDY-v0.1.md)。
