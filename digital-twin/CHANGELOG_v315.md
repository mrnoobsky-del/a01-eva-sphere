# Changelog · A-01 v3.1.5

## Added
- Desktop inspector now occupies a real grid column next to the 3D stage.
- Mobile inspector now behaves as a bottom sheet; the stage remains visible above it and reduces height while the sheet is open.
- Added a two-leaf upward/outward opening concept to the deployable-module sequence.
- Added a transparent service vestibule with separate inner and outer gate leaves.
- Added a visual interlock sequence: the outer gate opens only while the inner boundary is shown as closed; the inner gate is released only after the outer boundary closes.
- Added paired vertical guide rails, stops, rollers and a synchronized carriage.
- Extended the deployable-module animation from 11.6 s to 13.2 s.

## Preserved
- v3.1.4 integrated scene and Living World baseline.
- Existing level navigation, object selection, LED service flow, radial guide concept, telescopic transition sleeve, shell and LED cassette systems.

## Validation
- GitHub file creation completed on `feature/a01-v315-responsive-inspector-dolek`.
- Source-level anchor checks passed for all intended replacements and the new CSS/3D objects.
- Browser viewport verification is still pending.
- No merge to `main`, no production deployment and no claim of engineering certification.

## Engineering boundary
All new door, vestibule, radial and vertical carriage elements are visual design hypotheses. They do not establish dimensions, structural adequacy, air leakage performance, weather resistance, fire compliance or safe operation.
