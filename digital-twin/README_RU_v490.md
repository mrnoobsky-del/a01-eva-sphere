## Lottie: три целевых сценария

1. **Загрузка 3D-модели.** Компактная орбитальная анимация видна только пока открыт экран подготовки.
2. **Первое появление Сферы.** Та же визуальная система используется в приветствии и отключается при его закрытии.
3. **Инженерная сервисная операция.** Небольшой индикатор появляется только во время активной демонстрации обслуживания внешней LED-кассеты.

Плеер `lottie-web 5.13.0` загружается лениво. Предусмотрены два CDN-адреса, проверка появления API плеера и тайм-аут каждого источника. Используется SVG-рендерер и CSS fallback. При скрытии вкладки анимации ставятся на паузу; при `prefers-reduced-motion` Lottie не запускается.

## Надёжность и управление

- Добавлены окно ошибки и повторная загрузка при проблеме запуска Three.js.
- Обрабатываются события потери и восстановления WebGL-контекста.
- Непрерывные сценические анимации ограничены частотой до 60 кадров/с; неподвижная сцена по-прежнему рендерится по запросу.
- Нативная адаптивная настройка pixel ratio, batching геометрии, LOD и выбор объектов сохранены.
- Добавлен fallback для браузеров без `ResizeObserver`.
- Приветственное окно удерживает клавиатурный фокус, закрывается через Escape и возвращает фокус к элементу, который его открыл.
- Нижняя FPS-панель, тест 10 секунд и публичные кнопки тестового вращения не возвращались.

## Проверка и границы

Три HTML-варианта прошли статическую проверку: синтаксический разбор встроенных JavaScript-блоков, JSON import map/Schema.org, проверку повторяющихся HTML ID, метаданных версии, canonical/OG/Schema URL и отсутствие старых FPS/rotation-test элементов.

**Браузерная проверка v4.9.0 ещё не выполнена.** Требуется проверить запуск 3D, три Lottie-сценария, сервисную демонстрацию, клавиатуру, мобильную компоновку и восстановление WebGL в браузере. Ограничитель 60 Гц не является измерением FPS: устойчивые 60 FPS не подтверждены. Three.js и Lottie загружаются с CDN; автономная offline-сборка не включена. Физическая Сфера не представляется построенной или введённой в эксплуатацию.
