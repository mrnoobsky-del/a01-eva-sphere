# A-01 v3.7.0 — changelog / журнал изменений / 变更记录

**21 November 2026 / 21 ноября 2026 / 2026年11月21日**

## English
- Preserved the v3.6.0 AIR-01 integrated scene as the parent build.
- Added a **Comfort** item to the main navigation.
- Added an embedded Human Comfort Engineering workspace with L00–L04 selection.
- Added switchable schematic layers for step-free route, lift core, escalators, wastewater and water supply.
- Added six sections: Access, Sanitary, Family, Water, Floors and Evacuation.
- Added RU/EN and application theme/language synchronization.
- Linked the accessibility standard and interactive floor/ceiling module.
- Clarified that this page is an interactive SVG engineering schematic, not new Three.js spatial geometry.
