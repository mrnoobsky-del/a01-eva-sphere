# A-01 v3.1.8 — 主网站版本与空间协调

**基线：** 已发布的网站版本 v3.1.6（`3.1.6-gullwing-crown-vent-calcs`），以及准备好的 Android-01 v3.1.7 集成。

## 更新内容
- 保留主球体几何和现有网站视觉风格。
- 协调废弃物分类服务模块与外置货运电梯入口及过渡桥。
- 分离 MEP 与 HVAC 区域，并为楼板和基座增加独立穿孔。
- 将供热主管移至基础板下方，将 HVAC 路线移至外侧服务环带。
- 协调客梯塔、中庭边缘、连接桥和上层廊道支柱。
- 移除重复的互动楼梯几何，保留主场景中已有的楼梯。
- 对齐 Android-01 通道、门框和现有楼梯入口标记。
- 修复窄门扇的开启动画。

## 验证与限制
Agent 路线/任务测试、空间净距审计测试均通过。四个代理模块和内嵌 HTML ES 模块语法检查通过。HTML ID 检查发现 321 个唯一 ID，无重复项。ZIP 完整性检查通过。

选定接口包络的分析检查不是完整的三角网格碰撞检测或 BIM 协调。坐标仍为示意场景单位，并未校准为米。尚未完成实时浏览器/WebGL/GPU 漫游和实体测试。uCoz 网站未自动更新。
