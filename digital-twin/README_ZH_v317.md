# A-01 v3.1.7 — 主网站版本与 Android-01 Agent Runtime

**基线：** https://evasphere.usite.pro/ 当前发布的 A-01 v3.1.6 网站版本（`3.1.6-gullwing-crown-vent-calcs`）。v3.1.7 延续主球体场景，而不是用独立的 X 实验场景替换它。

## 更新内容
- 保留 v3.1.6 的主穹顶场景、五个楼层、模块、环廊、中庭、调度室、能源与气候面板。
- 在主导航中增加 Android-01 页面。
- 复用现有 `window.EVA_SPHERE`、Three.js 场景、`CONFIG.levelY` 和场景 `items`，不创建第二个独立场景。
- 增加程序化 17 骨骼 Android-01 模型，以及安装在头部骨骼上的独立眼部摄像机。
- 增加五层路线图：现有场景对象作为目的地，并使用示意性环廊路径点和楼层连接构建临时连通图。
- 增加任务提议、操作员明确批准、顺序执行和到达验证流程；保留 Stop 停止操作。
- 眼部摄像机需要单独由操作员启动；本地帧捕获不会自动上传网络。

## 技术与安全边界
每层路线包含 24 个示意环廊节点和 3 组概念楼层连接。这不是实际导航网格，也不能证明电梯可用、路径无碰撞、无障碍或疏散合规。坐标是 Three.js 示意单位，不是米。尚未实现 navmesh、碰撞求解或人群仿真。

未连接外部 AI 规划模型；当前界面使用内置检查任务。X 版本中的 Sensory Bridge/MCP/HTTP 未接入主页面，视频帧不会传送到外部服务。浏览器中的人工批准只是工作流程控制，并非安全边界，也不是经认证的实体机器人急停。不会控制执行器、门、电梯、BMS、暖通、电力或消防系统。

## 验证与状态
代理模块和嵌入式 ES 模块语法检查通过。自动测试覆盖五层地图、场景目的地、跨楼层路线、到达验证、姿态/视线限制、Stop 以及未经批准不移动。尚未进行真实浏览器/WebGL/GPU 测试，也未连接实体机器人或设备。

**状态：Prototype / 本地检查通过。** HTML 是准备好的构建版本，并非自动部署到 uCoz。手动替换前请备份在线页面，并在桌面和移动浏览器中验证。完整 HTML 与源模块另行提供 ZIP；本 PR 发布文档，不包含作为 GitHub Release Asset 的 1.6 MB HTML。
