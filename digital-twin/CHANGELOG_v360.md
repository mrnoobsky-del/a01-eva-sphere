# A-01 v3.6.0 — changelog / журнал изменений / 变更记录

**19 November 2026 / 19 ноября 2026 / 2026年11月19日**

## English
- Added AIR-01 as a selectable global scene object with ID `A01-AIR-01`.
- Added a conceptual 3D external MRE resource factory, product-gas conditioning, double-boundary transfer interface and clean-side ECLSS plant.
- Added visual representations of water electrolysis, CO₂ sorbent beds, Sabatier reactor, gas analyser, O₂ / H₂ / inert-gas / water buffers.
- Added separate O₂, CO₂-return and water distribution risers and ring routes across L00–L04.
- Added four display modes: full loop, oxygen production, air recovery and MRE stopped / reserve.
- Added AIR-01 navigation, toolbar toggle, engineering panel, object profile, global search and scene API state.
- Added visible four-person planning values and the unresolved CO₂ residual.
- Updated HTML metadata and footer to v3.6.0.
