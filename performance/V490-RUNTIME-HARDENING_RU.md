# A-01 v4.9.0 — runtime и производительность

## Рендеринг сцены

Сцена A-01 сохраняет demand-driven схему: изменение камеры, объекта или параметра запрашивает кадр; при активной анимации цикл продолжается. Для непрерывной работы добавлен интервал не менее `1000 / 60` мс между отрисовками. На мониторе с высокой частотой обновления это ограничивает сценический цикл примерно 60 Гц; на более медленном устройстве частота будет ниже, а реальные кадры могут пропускаться.

Ограничитель не является бенчмарком. Целевой бюджет кадра 16,67 мс, p95/p99 и устойчивые 60 FPS требуют отдельного измерения на эталонных устройствах по протоколу `performance/README_RU.md`.

## Adaptive quality

Нативный контроллер адаптивного pixel ratio сохранён. Он может менять разрешение рендеринга по наблюдаемой длительности кадров. Batching, feature picking и LOD не удалялись. Нижний FPS HUD и тест 10 секунд остаются удалёнными.

## Lottie lifecycle

Lottie используется только для загрузки модели, приветствия и активной сервисной демонстрации. Player загружается лениво; каждый CDN имеет timeout, проверяется API `window.lottie.loadAnimation`, второй источник используется при ошибке, истечении времени или неполной загрузке. Loading SVG уничтожается, когда экран подготовки закрыт. Приветствие и сервисная анимация ставятся на паузу при скрытии вкладки. При системном reduced motion Lottie не запускается.

## Ошибки и восстановление

Если Three.js не инициализировался, пользователь видит сообщение, подробность ошибки и кнопку повтора. Потеря WebGL-контекста останавливает цикл рендеринга и показывает то же окно состояния; при событии восстановления выполняется resize и запрашивается новый кадр. Поведение восстановления надо подтвердить в браузере/на устройстве.

## Известные ограничения

- Three.js 0.185.0 и Lottie Web 5.13.0 загружаются с CDN; без сети полная 3D-сцена не гарантируется.
- Автономный offline-пакет Three.js, addons и Lottie в этот выпуск не включён.
- Browser/WebGL и FPS benchmark v4.9.0 ещё не выполнялись.
- Программная оптимизация не подтверждает конструктивную, энергетическую или эксплуатационную безопасность физического объекта.
