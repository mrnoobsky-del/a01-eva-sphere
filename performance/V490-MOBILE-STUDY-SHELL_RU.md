# A-01 v4.9.0 — мобильная оболочка для изучения

**Тип:** отдельная тестовая HTML-страница, не замена основной 3D-сборки.  
**Основа:** уже опубликованный Wix preview eva-sphere-a01-v490-quality-experience-preview.html.

## Что делает оболочка

- Загружает существующий preview v4.9.0 в iframe того же сайта.
- Даёт верхнюю горизонтальную навигацию по обзору, уровням, пространствам, климату, энергии, расчётам, документации, реестру и инженерии.
- Перенаправляет быстрые кнопки на соответствующие элементы навигации основного приложения.
- На узких экранах через CSS override скрывает дублирующий верхний интерфейс приложения и левую панель, оставляя сцену и контекстную панель; navigation shell становится главным быстрым переключателем.
- Сохраняет вход в режим прогулки, внутреннее меню модели и полноэкранный режим.
- При недоступности iframe показывает ссылку для открытия оригинала.

## Границы проверки

Оболочка не меняет исходный Three.js renderer и не является доказательством более высокого FPS. v4.9.0 уже содержит demand-driven rendering, adaptive pixel ratio, batching и LOD; реальные показатели FPS и мобильная браузерная приёмка должны быть сняты на физических устройствах по протоколу performance/README_RU.md.
