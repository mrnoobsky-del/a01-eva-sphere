# A-01 v4.9.2 — центр управления и чат Евы

**Дата:** 27 ноября 2026 года  
**Основа:** отдельная ветка от v4.9.1 mobile performance hardening. Основная ветка и опубликованная главная страница не изменяются.

## Существующие компоненты
- Реальный чат Евы с Cloudflare Worker `/site`.
- Обработка VisualViewport для экранной клавиатуры.
- 3D API `window.EVA_SPHERE` с методами переключения уровней, режимов прогулки, климата, энергии и внешнего обзора.

## Изменения v4.9.2
- Быстрая командная панель: обзор, прогулка, климат, энергия, внешний вид, уровни 00–04.
- Команды из чата: «покажи обзор», «уровень 2», «покажи уровень 2», «прогулка», «климат», «энергия», «снаружи», «внутри», «найди название».
- Контекстный статус отражает текущий ракурс, режим и выбранный объект.
- Worker получает короткий текстовый контекст текущей сцены для более предметного ответа.
- Desktop чат размещён над рабочей зоной 3D без общего затемнения сцены.
- Mobile чат занимает видимую область экрана; VisualViewport пересчитывает её при открытии экранной клавиатуры; input установлен в 16px, сообщения прокручиваются отдельно.

## Безопасная граница
Автоматически выполняются только allowlist-команды, введённые пользователем или вызванные кнопками. Текстовые ответы LLM не запускают действия. «Найти» выбирает объект только при одном совпадении. Команды меняют только цифровое отображение, не реальное оборудование. Для полноценного AI tool-calling требуется отдельное изменение Cloudflare Worker: структурированный формат proposal, проверка allowlist и подтверждение пользователя.

## Приёмка
Требуется проверить на реальных desktop, Android и iOS:
- открытие/закрытие чата, клавиатуру, поворот экрана, safe areas;
- переключение всех пяти уровней;
- обзор, прогулку, климат, энергию, внешний вид;
- поиск уникального объекта и обработку неоднозначных результатов;
- три 60-секундных прогона производительности на каждом эталонном устройстве.

**Не заявляется:** достижение 60 FPS на любом устройстве и управление физическими системами Сферы.
