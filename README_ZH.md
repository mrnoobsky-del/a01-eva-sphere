# A-01 — 伊娃之球（The Sphere of Eva）

**能源 · 智能 · 生命**

A-01 是一个长期、以人为中心的环境构想与开放开发记录，探索如何将建筑、能源系统、数字基础设施、知识保存与 AI 辅助服务整合在一起。

> A-01 并不表示实体穹顶已经建成。此仓库记录研究、设计探索、软件原型与未来实施所需的开放问题。

## 项目原则

- **以人为中心。** 技术应支持人的尊严、安全与可及性。
- **持续性。** 知识、治理与交接机制应允许项目超越单一创始人而持续发展。
- **避免单点依赖。** 设计应考虑数据可迁移、备份、人类替代流程以及供应商和技术替换。
- **可问责的自主性。** 财务、关键基础设施、安全及影响个人权利的决策必须有人类监督。
- **如实报告状态。** 原型、概念、研究、计划工作和已验证部署必须明确区分。
- **关怀不能取代人。** EVA CARE 应协助人们联系工作人员和合格服务，而不是取代他们。

## A-01 的四个独立建筑层

A-01 信息标准把建筑分成四个不同系统：

1. **主结构 STR：** 基础、柱、环梁、肋、节点和支撑。
2. **内部环境与生命安全边界 ENV：** 空气、水汽、热工、防火、防烟、开口和疏散。
3. **可更换外部模块 CAS：** 外部天气面板、遮阳、光伏、传感器和维护导轨。
4. **内部体验层 SKY：** LED 数字天幕、照明、声学、标识和可变饰面。

可更换面板不能悄悄成为主结构的一部分。面板故障不应破坏主框架、内部环境边界或有人使用的空间。

## 几何、计算与工程状态

数字孪生中的坐标目前仍为 **model-unit（模型单位）**，尚未校准为米。组件登记册区分几何数据与工程数据：

- 已有参数几何：可以记录面积、半径、曲线长度、角度和位置。
- 尚缺的物理数据：质量、材料牌号、截面、螺栓、风压、雪荷载、刚度、承载力和疲劳寿命。
- 缺失值保持为空，不从渲染模型推测。
- “proposed” 表示概念方案，不等于已计算、已审核或获批。

黄金比例研究目前只把 φ = (1 + √5) / 2 用作两条环形通行带的视觉比例。它不是结构安全系数，也不能代替疏散、无障碍或防火规范。

## 开源工程工具参考

- [FreeCAD FEM](https://wiki.freecad.org/FEM_Workbench) 与 [CalculiX](https://www.calculix.de/)：有限元分析候选工具。
- [Frame3DD](https://github.com/hpgavin/frame3dd)：框架和桁架分析。
- [PyNite](https://github.com/JWock82/Pynite)：Python 结构有限元分析。
- [EnergyPlus AirflowNetwork](https://energyplus.readthedocs.io/en/latest/guides/engineering-reference/13.1-airflownetwork-model.html)：多区域气流与自然通风建模。
- [OpenFOAM](https://www.openfoam.com/)：热浮力流动与 CFD 研究。
- [IfcOpenShell / Bonsai](https://docs.ifcopenshell.org/bonsai.html)：IFC / BIM 数据工作流。

这些工具是分析平台，不是 A-01 的现成认证设计。实际计算仍需要确定场地、尺度、材料、边界条件、荷载组合、规范和专业审核。

## 安全、工程与治理

除非明确标记为已验证，仓库中的工程数值和系统说明均为初步概念。它们不是施工图、认证计算、专家意见、许可或安全证明。

实体实施需要场地测量、地质与气候研究、合格建筑师和工程师、当地法规审查、独立复核与调试。关键功能不能依赖云服务、单一供应商或 AI 的不受监督决策。
